Brahma-Purāṇa

Kapitel 209: dvividavadhaḥ Die Tötung des Dvivida

Der Affe Dvivida, Freund des getöteten Dämonen Naraka, verübt aus Rache gegen die Götter weitreichende Verwüstungen (Opferstörung, Zerstörung von Städten, Flutwellen). Als er Balarāma und dessen Gattinnen bei einem Trinkgelage verspottet und angreift, erschlägt Balarāma ihn im Faustkampf; die Götter lassen einen Blütenregen herabfallen und preisen die Tat.

Vers 1

śṛṇudhvaṃ munayaḥ sarve balasya balaśālinaḥ / kṛtaṃ yad anyad evābhūt tad api śrūyatāṃ dvijāḥ //

Vyāsa sprach: „Höret, ihr Weisen alle, von einer weiteren Tat, die von dem kraftvollen Bala vollbracht wurde – auch diese möge gehört werden, o Zweifachgeborene.

Wort für Wort
śṛṇudhvaṃ munayaḥ sarve balasya balaśālinaḥ /
Höret, ihr Weisen alle, von einer weiteren Tat, die von dem kraftvollen Bala vollbracht wurde –
kṛtaṃ yad anyad evābhūt tad api śrūyatāṃ dvijāḥ //
auch diese möge gehört werden, o Zweifachgeborene.
