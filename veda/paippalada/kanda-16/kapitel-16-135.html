Hymne 16.135 Virāj wird von Asuras bis Schlangen gemolken

Vers 16.135.1

sod akrāmat sāsurān āgacchat / tām asurā upāhvayanta māya ehīti | / tasyā virocanaḥ prāhrādur vatsa āsīd ayaspātraṃ pātram | / tāṃ dvimūrdhārtviyo 'dhok tāṃ māyām adhok | / tāṃ māyām asurā upa jīvanty / upajīvanīyo bhavati ya evaṃ veda ||

Sie ging hinauf, sie kam zu den Asuras; / die Asuras riefen sie herbei: „Komm, Māyā (Zauberkraft)!“ / Ihr Kalb war Virocana Prāhrādi, das Gefäß ein eisernes Gefäß. / Dvimūrdhan Ārtviya molk sie, er molk die Māyā. / Von dieser Māyā leben die Asuras; / einer, von dem man lebt, wird er, wer so weiß.

Vers 16.135.2

(…) sā pitṝn āgacchat see 1a / tāṃ pitara upāhvayanta svadha ehīti | / tasyā yamo vaivasvato vatsa āsīd rajatapātraṃ pātram | / tām antako mārtayo 'dhok tāṃ svadhām adhok | / tāṃ svadhāṃ pitara upa (…) || see 1ef

[Sie ging hinauf,] sie kam zu den Vätern; / die Väter riefen sie herbei: „Komm, Svadhā!“ / Ihr Kalb war Yama Vaivasvata, das Gefäß ein silbernes Gefäß. / Antaka Mārtaya molk sie, er molk die Svadhā. / Von dieser Svadhā leben die Väter; / [einer, von dem man lebt, wird er, wer so weiß.]

Vers 16.135.3

(…) sā manuṣyān āgacchat see 1a / tāṃ manuṣyā upāhvayanterāvaty ehīti | / tasyā manur vaivasvato vatsa āsīt pṛthivīpātraṃ pātram | / tāṃ pṛthur vainyo 'dhok tāṃ kṛṣiṃ ca sasyaṃ cādhok | / tāṃ kṛṣiṃ ca sasyaṃ ca manuṣya upa (…) || see 1ef

[Sie ging hinauf,] sie kam zu den Menschen; / die Menschen riefen sie herbei: „Komm, Irāvatī (Labung)!“ / Ihr Kalb war Manu Vaivasvata, das Gefäß ein Erdgefäß. / Pṛthu Vainya molk sie, er molk Ackerbau und Feldfrucht. / Von Ackerbau und Feldfrucht leben die Menschen; / [einer, von dem man lebt, wird er, wer so weiß.]

Vers 16.135.4

(…) sā devān āgacchat see 1a / tāṃ devā upāhvayantorja ehīti | / tasyā indro vatsa āsīd dārupātraṃ pātram | / tāṃ savitādhok tām ūrjam adhok | / tām ūrjaṃ devā upa (…) || see 1ef

[Sie ging hinauf,] sie kam zu den Göttern; / die Götter riefen sie herbei: „Komm, Kraft (ūrj)!“ / Ihr Kalb war Indra, das Gefäß ein hölzernes Gefäß. / Savitṛ molk sie, er molk die Kraft. / Von der Kraft leben die Götter; / [einer, von dem man lebt, wird er, wer so weiß.]

Vers 16.135.5

(…) sā sapta ṛṣīn āgacchat see 1a / tāṃ sapta ṛṣaya upāhvayanta brahmaṇvaty ehīti | / tasyāḥ somo vatsa āsīc chandaḥpātraṃ pātram | / tāṃ bṛhaspatir āṅgiraso 'dhok tāṃ brahma ca tapaś cādhok | / tad brahma ca tapaś ca sapta ṛṣaya upa (…) || see 1ef

[Sie ging hinauf,] sie kam zu den sieben Ṛṣis; / die sieben Ṛṣis riefen sie herbei: „Komm, Brahmanvatī (Brahman-Reiche)!“ / Ihr Kalb war Soma, das Gefäß das Metrum. / Bṛhaspati Āṅgirasa molk sie, er molk Brahman und Glut (tapas). / Von Brahman und Glut leben die sieben Ṛṣis; / [einer, von dem man lebt, wird er, wer so weiß.]

Vers 16.135.6

(…) sā gandharvāpsarasa āgacchat see 1a / tāṃ gandharvāpsarasa upāhvayanta puṇyagandha ehīti | / tasyāś citrarathaḥ sauryavarcaso vatsa āsīt puṣkaraparṇaṃ pātram | / tāṃ vasuruciḥ sauryavarcaso 'dhok tāṃ puṇyaṃ gandham adhok | / taṃ puṇyaṃ gandhaṃ gandharvāpsarasā upa (…) || see 1ef

[Sie ging hinauf,] sie kam zu den Gandharvas und Apsaras; / die Gandharvas und Apsaras riefen sie herbei: „Komm, Puṇyagandha (Wohlgeruch)!“ / Ihr Kalb war Citraratha Sauryavarcasa, das Gefäß ein Lotusblatt. / Vasuruci Sauryavarcasa molk sie, er molk den guten Duft. / Von dem guten Duft leben die Gandharvas und Apsaras; / [einer, von dem man lebt, wird er, wer so weiß.]

Vers 16.135.7

(…) sā puṇyajanān āgacchat see 1a / tāṃ puṇyajanā upāhvayanta tirodha ehīti | / tasyāḥ kubero vaiśravaṇo vatsa āsīd āmapātraṃ pātram | / tāṃ rajatanābhiḥ kāberako 'dhok tāṃ tirodhām adhok | / tāṃ tirodhāṃ puṇyajanā upa (…) || see 1ef

[Sie ging hinauf,] sie kam zu den Puṇyajanas (Yakṣas); / die Puṇyajanas riefen sie herbei: „Komm, Tirodhā (Verschwinden)!“ / Ihr Kalb war Kubera Vaiśravaṇa, das Gefäß ein ungebranntes (rohes) Gefäß. / Rajatanābhi Kāberaka molk sie, er molk das Verschwinden. / Vom Verschwinden leben die Puṇyajanas; / [einer, von dem man lebt, wird er, wer so weiß.]

Vers 16.135.8

sod akrāmat sā sarpān āgacchat / tāṃ sarpā upāhvayanta viṣavaty ehīti | / tasyās takṣako vaiśāleyo vatsa āsīd alābupātraṃ pātram | / tāṃ dhṛtarāṣṭra airāvato 'dhok tāṃ viṣam adhok | / tad viṣaṃ sarpā upa jīvanty / upajīvanīyo bhavati ya evaṃ veda ||

Sie ging hinauf, sie kam zu den Schlangen; / die Schlangen riefen sie herbei: „Komm, Viṣavatī (Gift-Reiche)!“ / Ihr Kalb war Takṣaka Vaiśāleya, das Gefäß ein Flaschenkürbis-Gefäß. / Dhṛtarāṣṭra Airāvata molk sie, er molk das Gift. / Von diesem Gift leben die Schlangen; / einer, von dem man lebt, wird er, wer so weiß.

Vers 16.135.9

tasmād yasmā alābunābhiṣiñcen Bhatt. yasmādalābunā / manasā tvā pratyāhanmīty enaṃ pratyāhanyāt | / yat pratyāhanti viṣaṃ pratyāhanti / na ca pratyāhanti viṣam anu prasicyate | / viṣam asyāpriyaṃ bhrātṛvyaṃ hanti ya evaṃ veda ||

Deshalb: Wen man mit dem Kürbisgefäß [Gift/Wasser] übergießt (abhiṣiñcet), / den soll man mit „Mit dem Sinn schlage ich dich zurück“ zurückschlagen. / Wenn er zurückschlägt, schlägt er das Gift zurück; / und wenn er nicht zurückschlägt, wird ihm das Gift nachgegossen. / Das Gift und seinen unlieben Rivalen schlägt er tot, wer so weiß.
