Paippalāda-Saṃhitā · Kāṇḍa 17

Hymne 17.14 Gegen die Sadānvā-Dämoninnen (III)

Vers 17.14.1

duḥsaṃkāśe bhīmacakṣo Bhatt. duḥśaṅkāśe / nagne bhaṇve sadānve / dhrājiṃ tviṣiṃ śucim agnim / arāyi kim ihecchase | / dhūmaṃ mābhi pra gāyi / ni stauṣāmi sadānve ||

Schlecht Aussehende, Furchtaugige, / Nackte, Bhaṇvā, Sadānvā: / Glanz [und] Pracht, das reine Feuer: / Geizige, was willst du hier? / Möge ich nicht auf den Rauch hin angestimmt werden; / ich lobpreise die Sadānvā [nieder/weg] [?].

Vers 17.14.2

kaṅkyekā prakhidaikā / kim ic chāntyabhiśrayā | / caranti naktaṃ durṇāmno / arāyīḥ sūtikaiṣyas Bhatt. rāyī(ḥ) / tā ito nāśayāmasi ||

Eine Kaṅkī, eine Prakhidā, / was sucht die Ruhige, die Herbeikriechende? / Nachts streifen die Bösenamigen umher, / die Geizigen, die Gebärerinnen [?]: / diese vertreiben wir von hier.

Vers 17.14.3

apakrathām abhiśrayām / ānṛtyantīṃ kutūhalām | / kusūlīṃ rathabhañjanīṃ / khalāj jātās trikūkvas / tā ito nāśayāmasi ||

Die Apakrathā, die Abhiśrayā, / die Tanzende, die Neugierige, / die Kusūlī, die Wagenbrecherin, / [die] auf der Tenne Geborenen, die Dreibuckeligen: / diese vertreiben wir von hier.

Vers 17.14.4

yā vikeśīr unmadityā- / -urarā ghoracakṣavaḥ | / śīrśāṇy anyā anyāsāṃ / vitāvantīr ivāsate / sadānvā brahmaṇaspate / paro bhrūṇāny arpaya ||

Die Haarlosen [oder: mit gelöstem Haar], die Rasenden, / die Schrecklichäugigen, in der Nähe: / bei diesen sind Häupter von anderen, von anderen, / als [wären sie] ausgespannt, sie sitzen da: / die Sadānvās, o Brahmaṇaspati, / schicke die Leibesfrüchte hinweg.

Vers 17.14.5

yāsāṃ gandho nānārūpaḥ / paryaiti puruṣaṃ pathi | / tā agniḥ sahatām ito / jātavedāḥ sadānvāḥ ||

Deren vielgestaltiger Geruch / den Menschen auf dem Weg umgibt: / diese soll Agni von hier überwältigen, / Jātavedas, die Sadānvās.

Vers 17.14.6

yāḥ puruṣaṃ dahyamānaṃ / śūnyam agnau jighatsanti | / bhaṇvā niṣkuṣṭā nāmāsi / muṣṭāgreṇa sadānvās / tā ito nāśayāmasi ||

Die den im Feuer verbrennenden, / leeren Menschen verschlingen wollen: / ‚Bhaṇvā, Ausgestoßene, Namenlose bist du‘ [?], / mit der Faust vorn [schlage ich] die Sadānvās: / diese vertreiben wir von hier.

Vers 17.14.7

yā ucitā āvapane / śuṣkaṃ khādanti maṣmasaṃ / vaḍavā gardabhīr iva | / nāśayāmaḥ sadānvāḥ ||

Die die auf der Streu Gewohnten sind, / trockenen Staub [Asche] fressen, / wie Stuten, wie Eselinnen: / wir vernichten die Sadānvās.

Vers 17.14.8

garbhān ekaḥ prati morśaṃ Bhatt. emend. mṛśaṃ? / yā adanti sadānvāḥ | / ucitās tanvaṃ striyā / gāva ā rohiṇīr iva / tā ito nāśayāmasi ||

Die eine [Sadānvā] [nimmt] Leibesfrüchte ... [?], / die Sadānvās, die [sie] fressen: / den Leib der Frau, / wie Kühe [die] Rotkühe [?]: / diese vertreiben wir von hier.

Vers 17.14.9

yāḥ pitṛyāt saṃbhavanti- / -indrajā naḥ sadānvāḥ | / apa mityam ivābhṛtaṃ / punas tā prati dadmasi ||

Die aus der väterlichen [Seite] hervorgehen, / uns von Indra Geborenen [?], Sadānvās: / wie ein zu Unrecht Geholtes [?] / geben wir sie wieder zurück.

Vers 17.14.10

āmādinīḥ krūrādinīr / anagnigandhyādinīḥ | / amuṃ paretyoddhitaṃ / śavam atta sadānvāḥ | / śavaḥ kevala ācāraḥ / kim u śālāsv icchatha ||

Rohfleischesserinnen, Blutfresserinnen, / Nicht-nach-Feuer-Riechende-Fresserinnen: / den dort hingegangenen Toten, / den Leichnam [dort] fresst, ihr Sadānvās. / Ein Leichnam ist bloße Kost [?] – / was wollt ihr in den Hütten?
