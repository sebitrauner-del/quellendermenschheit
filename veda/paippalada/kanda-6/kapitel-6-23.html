Paippalāda-Saṃhitā · Kāṇḍa 6

Hymne 6.23 Fluch: Trennung von Ehepaar

Vers 6.23.1

nir ṇudaināṃ pra ṇudaināṃ / svān nipadanād adhi | / vibhraṃśam asyai kṛṇmo / vi gṛhair bhraṃśatām asau ||

Stoße sie hinaus, stoße sie fort / von ihrem eigenen Lagerplatz! / Trennung bereiten wir ihr; / aus den Häusern soll jener [NN] herausfallen.

Vers 6.23.2

apāñcaṃ patim ā kurv / adharācīṃ striyaṃ naya | / atīmān daśa parvatān / atīmā nāvyā daśa ||

Mache den Gatten rückwärts gewandt, / führe die Frau abwärts gewandt fort: / über diese zehn Berge hinweg, / über diese zehn Schiffbaren [Gewässer].

Vers 6.23.3

adharācīm avācīm / atho akuśalāṃ diśam | / vibhraṃśam asyai kṛṇmas / tenaināṃ pra dahāmasi ||

Abwärts gewandt, nach unten, / und in die unheilvolle Himmelsrichtung: / Trennung bereiten wir ihr, / damit verbrennen wir sie.

Vers 6.23.4

āja nir aja bilaṃ / bilād araṇyam ā kurv / araṇyād araṇaṃ janam | / mṛgām̐ anu pra pātaya / vātasyaināṃ śikhāṃ kuru ||

Treibe [sie] hinaus in die Höhle; von der Höhle / mache [sie] zum Wald, / vom Wald zu einem ungastlichen Volk [?]. / Jage [sie] den Wildtieren nach; / mache sie zur Haarspitze des Windes.

Vers 6.23.5

vātāgre asyā hṛdayaṃ / mano reṣmaṇi dadhmasi | / vibhraṃśam asyai kṛṇmo / vidhvaṃśam āsaktaṃ dame ||

An der Spitze des Windes [setzen wir] ihr Herz, / ihren Geist setzen wir in den Ansturm [/ Sturm]; / Trennung bereiten wir ihr, / Zerstörung, im Haus angeheftet.

Vers 6.23.6

sarvam anu pari plavatām / antarā dyāvāpṛthivī ubhe | / yathānavadhṛtā carād / vṛṣatūlam ivopari ||

Sie soll allem nachtreiben, / zwischen Himmel und Erde, den beiden, / so dass sie ungehemmt umherziehe / wie eine [leichte] Flocke [vṛṣatūla] oben darüber.

Vers 6.23.7

aśam asyai vāto vātv / aśaṃ tapatu sūryaḥ | / atho yad annam aśnāti / tad asyai viṣavattaram ||

Unheil [?] soll für sie der Wind wehen, / Unheil soll die Sonne brennen; / und was an Speise sie isst, / das sei für sie giftiger [als Gift].

Vers 6.23.8

siṃhas te astu cakṣuṣa ity ekā ||

„Ein Löwe sei dir für das Auge“ – dies ist eine [Strophe].

Vers 6.23.9

eṣa vām agnir antarā / sa viṣvañcau vy asyatu | / yathā vāṃ na sahāsaty / uttarasmiṃś canāyuṣi ||

Dies ist euer Agni, dazwischen; / er soll die beiden auseinandertreiben, / so dass für euch beide kein Beisammensein gelingen möge, / auch nicht in späterem Lebensalter [?].

Vers 6.23.10

ut pātaya śimidāvati / pra pātaya śimidāvati | / imau vy asya dampatī / pakvaṃ māṃsam ivāsinā ||

Schleudere sie hoch, Śimidāvatī, / schleudere sie fort, Śimidāvatī! / Diese beiden Eheleute zerlege / wie gekochtes Fleisch mit dem Schwert.

Vers 6.23.11

meyam asmin patau raṃsta / mo asmiñ chayane sve | / jahātu vasanaṃ svam / ahir jīrṇām iva tvacam ||

Diese soll bei diesem Gatten keine Lust finden, / nicht auf diesem ihrem eigenen Lager; / sie soll ihr Gewand ablegen, / wie die Schlange die alte Haut.

Vers 6.23.12

yathā mṛtāś ca jīvāś ca- / -asmiṃl loke vyokasaḥ | / evemau dampatī stām / asmiṃl loke vyokasau ||

Wie Tote und Lebende in dieser Welt / getrennt hausen, / so sollen diese beiden Eheleute / in dieser Welt getrennt hausen.
