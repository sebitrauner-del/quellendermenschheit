Paippalāda-Saṃhitā · Kāṇḍa 9

Hymne 9.29 Liebeszauber mit Aśvattha und Kuṣṭha (2)

Vers 9.29.1

aśvattham agnim ājyaṃ / dūtān kṛṇve manojavān | / agniś carum ivārciṣā / kāmo vidhyatu tvā mama / pra (…) || see 9.28.1e

Den Aśvattha, Agni, die Schmelzbutter / mache ich zu gedankenschnellen Boten. / Agni [erhitze dich] wie einen Kochtopf mit der Flamme: / das Verlangen soll dich durchbohren, mein [Verlangen]. / (Refrain: „Flieg hervor, [getrieben] von meinem Sehnen.“)

Vers 9.29.2

śayānam agna āsīnam / aśvatthaś ca savāsinau | / carantam upatiṣṭhantaṃ / mamādhibhir vi vidhyataṃ / pra (…) || see 9.28.1e

Den Liegenden, Agni, den Sitzenden — / Aśvattha und [du] als Zusammen-Wohnende — / den Gehenden, Dastehenden: / mit meinen Sehnsüchten sollt ihr beide [ihn] durchbohren. / (Refrain: „Flieg hervor, [getrieben] von meinem Sehnen.“)

Vers 9.29.3

carantaṃ tvā tiṣṭhantam / āsīnam api saṃsadi | / reṣmā tṛṇam iva mathnātu / dahan kāmaratho mama / pra (…) || see 9.28.1e

Dich, den Gehenden, Dastehenden, / Sitzenden, auch in der Versammlung: / wie ein Sturm [?] (reṣmā) den Halm zerreibt, / so soll der brennende Wagen meines Begehrens [dich zerreiben]. / (Refrain: „Flieg hervor, [getrieben] von meinem Sehnen.“)

Vers 9.29.4

yathendrāyāsurān / arandhayad bṛhaspatiḥ | / evā tvam agne aśvatthān / amūn mahyam ihānaya / pra (…) || see 9.28.1e

Wie Bṛhaspati für Indra / die Asuras unterwarf, / so bringe du, Agni, jene Aśvatthas [?] / mir hierher. / (Refrain: „Flieg hervor, [getrieben] von meinem Sehnen.“)

Vers 9.29.5

ahaṃ te mana ā dada / aiḍena saha medinā | / devā manuṣyā gandharvās / te mahyaṃ randhayantu tvā / pra (…) || see 9.28.1e

Ich nehme deinen Sinn an mich, / samt dem Aiḍa [und] dem Gefährten (medin) [?]; / Götter, Menschen, Gandharvas: / sie sollen dich mir unterwerfen. / (Refrain: „Flieg hervor, [getrieben] von meinem Sehnen.“)

Vers 9.29.6

yathā aśvatthasya parṇāni / nelayanti kadā cana | / evāsau mama kāmena / māva svāpsīt kadā cana / pra patāto mamādhyā ||

Wie die Blätter des Aśvattha / niemals stillstehen [?] (nelayanti), / so soll jene durch mein Begehren / niemals einschlafen. / Flieg hervor, [getrieben] von meinem Sehnen.

Vers 9.29.7

kuṣṭhaṃ tapanti marutaḥ svādhyaṃ / dūra-ājānaṃ svarayanto arciṣā | Bhatt. svādhyandura ājānaṃ / yathā na svapāt katamac canāhar / aiva gacchān mamādhyā ||

Den Kuṣṭha erhitzen die Maruts, den gut zu Bedenkenden [?], weithin Getriebenen [?], / mit ihrer Flamme tönen lassend, / damit sie an keinem Tag schlafe: / sie soll herkommen durch mein Sehnen.
