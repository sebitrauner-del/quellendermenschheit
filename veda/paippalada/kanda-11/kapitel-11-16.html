Paippalāda-Saṃhitā · Kāṇḍa 11

Hymne 11.16 Die Wasser und ihre Herren (Prosa)

Vers 11.16.1

ūrdhvaśrito vai nāmaitā āpo yad oṣadhayaś ca vanaspatayaś ca / tāsām agnir adhipatiḥ | / yo vā etā ūrdhvaśrita āpo vedāgnim adhipatim | / yathaitam etā ūrdhvā upatiṣṭhanty / evainam ūrdhvā upa tiṣṭhanty / adhipatir bhavati svānāṃ cānyeṣāṃ ca ya evaṃ veda ||

„Die ‚Aufrecht-Stehenden‘ heißen diese Wasser, nämlich die Pflanzen und die Bäume. / Ihr Herr ist Agni. / Wer diese Aufrechtstehenden Wasser kennt, Agni als Herrn: / wie diese sich aufrecht zu ihm stellen, / so stellen sich [Menschen] aufrecht zu ihm. / Er wird Herr über die Seinen und die anderen, wer so weiß.“

Vers 11.16.2

praskadvarīr vai nāmaitā āpo yat pṛṣvās / tāsām ādityo 'dhipatiḥ | / yo vā etāḥ praskadvarīr āpo vedādityam adhipatim | / yathaitā etasminn udyati praskandanty / evāsminn ā yati praskandanty / adhipatiḥ (…) || see 1e

„Die ‚Hervorspringenden‘ heißen diese Wasser, nämlich die Pṛṣvā-Tropfen. / Ihr Herr ist Āditya. / Wer diese Hervorspringenden Wasser kennt, Āditya als Herrn: / wie diese beim Aufgehen von ihm hervorspringen, / so springen sie ihm beim Kommen hervor. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.3

takvarīr vai nāmaitā āpo yāḥ sūdaya / tāsāṃ pṛthivy adhipatnī | / yo vā etās takvarīr āpo veda pṛthivīm adhipatnīm | / yathaitā etasyāṃ praṇutās takantīr yanty / evainena dviṣantaḥ praṇutā yanty / adhipatiḥ (…) || see 1e

„Die ‚Eilenden‘ heißen diese Wasser, nämlich die, die abfließen [?]. / Ihre Herrin ist die Erde. / Wer diese Eilenden Wasser kennt, die Erde als Herrin: / wie diese auf ihr fortgetrieben eilend gehen, / so gehen die Feinde durch ihn fortgetrieben. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.4

vaśinīr vai nāmaitā āpo yāḥ syandante / tāsāṃ varuṇo 'dhipatiḥ | / yo vā etā vaśinīr āpo veda varuṇam adhipatim | / yathaitam etāsāṃ syandamānānāṃ vaśam ādatta / evā dviṣatāṃ vaśam ā datte / 'dhipatiḥ (…) || see 1e

„Die ‚Gebietenden‘ heißen diese Wasser, nämlich die fließenden. / Ihr Herr ist Varuṇa. / Wer diese Gebietenden Wasser kennt, Varuṇa als Herrn: / wie man deren Fließenden Macht ergreift, / so ergreift er die Macht über die Feinde. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.5

ūrjo vai nāmaitā āpo yad gāvas / tāsāṃ tvaṣṭādhipatiḥ | / yo vā etā ūrja āpo veda tvaṣṭāram adhipatim | / ūrjasvī tejasvī bhavati / pra sāhasrān paśūn āpnoty / adhipatir bhavati (…) || see 1e

„‚Kraft‘ heißen diese Wasser, nämlich die Kühe. / Ihr Herr ist Tvaṣṭar. / Wer diese Kraft-Wasser kennt, Tvaṣṭar als Herrn: / er wird kraftvoll, glanzvoll; / er gewinnt Tausende Tiere. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.6

varco vai nāmaitā āpo yad ghṛtaṃ / tāsāṃ pūṣā adhipatiḥ | / yo vā etā varca āpo veda pūṣaṇam adhipatim | / varcasvī tejasvī bhavaty / utāsyānabhyaktasya mukhaṃ rocate / 'dhipatiḥ (…) || see 1e

„‚Glanz‘ heißen diese Wasser, nämlich die Butter. / Ihr Herr ist Pūṣan. / Wer diese Glanz-Wasser kennt, Pūṣan als Herrn: / er wird glanzvoll, strahlend; / und ihm, auch unbesalbt, leuchtet das Gesicht. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.7

ojo vai nāmaitā āpo yan madhu / tāsām indro 'dhipatiḥ | / yo vā etā oja āpo vedendram adhipatim | / ojasvī vīryāvān indriyāvī bhavati / pra rājasabhāyāṃ madhuparkam āpnoty / adhipatiḥ (…) || see 1e

„‚Stärke‘ heißen diese Wasser, nämlich der Honig. / Ihr Herr ist Indra. / Wer diese Stärke-Wasser kennt, Indra als Herrn: / er wird stark, heldenhaft, mit Indra-Kraft versehen; / in der Königsversammlung erlangt er den Madhuparka. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.8

ugrā vai nāmaitā āpo yad dhrādunayas / tāsāṃ maruto adhipatayaḥ | / yo vā etā ugrā āpo veda maruto 'dhipatīn | / ugro balavāna bhavati / mārutaṃ śardha ity enam āhur / adhipatiḥ (…) || see 1e

„‚Die Wilden‘ heißen diese Wasser, nämlich die brausenden [dhrādunayaḥ, Wolken?]. / Ihre Herren sind die Maruts. / Wer diese Wilden Wasser kennt, die Maruts als Herren: / er wird wild, kraftvoll; / ‚Marut-Schar‘ sagt man von ihm. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.9

maho vai nāmaitā āpo yad varṣaṃ / tāsāṃ parjanyo 'dhipatiḥ | / yo vā etā maha āpo veda parjanyam adhipatim | / mahasvī mitrabāho bhavaty / utainena svā nandanty asmākam ayam iti / tasmāt sarvo vṛṣṭe mahīyate / 'dhipatiḥ (…) || see 1e

„‚Größe‘ heißen diese Wasser, nämlich der Regen. / Ihr Herr ist Parjanya. / Wer diese Größe-Wasser kennt, Parjanya als Herrn: / er wird groß, freundesarmig [?]; / und ihm freuen sich die Seinen: „Unser ist dieser“; / darum wird jeder bei Regen groß. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.10

atimanyā vai nāmaitā āpo yat surā / tasām aśvinādhipatī | / yo vā etā atimanyā āpo vedāśvinādhipatī | / ati manyate bhrātṛvyān nainaṃ bhrātṛvyā ati manyante / tasmān matto mattam ati manyate / 'dhipatiḥ (…) || see 1e

„‚Übermütig‘ heißen diese Wasser, nämlich der Branntwein [surā]. / Ihre Herren sind die beiden Aśvins. / Wer diese Übermut-Wasser kennt, die Aśvins als Herren: / er überhebt sich über Vettern, und ihn überheben sich die Vettern nicht; / darum überhebt sich der Berauschte über den Berauschten. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.11

paricito vai nāmaitā āpo yāḥ karṣvāṃ / tāsāṃ yamo 'dhipatiḥ | / yo vā etāḥ paricita āpo veda yamam adhipatim | / pary enaṃ svāś ca viśyāś cāvaśyanty / adhipatiḥ (…) || see 1e

„‚Die Anhäufenden‘ heißen diese Wasser, nämlich die des Pflügens [karṣū, Furche]. / Ihr Herr ist Yama. / Wer diese Anhäufenden Wasser kennt, Yama als Herrn: / ihn umgeben die Seinen und die Stammesgenossen. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.12

rantayo vai nāmaitā āpo ya striyas / tāsāṃ kāmo 'dhipatiḥ | / yo vā etā rantīr āpo veda kāmam adhipatim | / ramante asmin ramaṇīyo bhavati kāma iva strīṇām / adhipatiḥ (…) || see 1e

„‚Die Erfreuenden‘ heißen diese Wasser, nämlich die Frauen. / Ihr Herr ist Kāma. / Wer diese Erfreuenden Wasser kennt, Kāma als Herrn: / sie freuen sich an ihm; er wird liebenswert, wie Kāma für Frauen. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.13

viśvabhṛto vai nāmaitā āpo yat puruṣas / tāsāṃ mṛtyur adhipatiḥ | / yo vā etā viśvabhṛta āpo veda mṛtyum adhipatim | / viśvasya bhartā bhavati viśvam enaṃ bibharty / āsya trayo 'gnayo gṛhe dhīyante dakṣiṇāgnir gārhapatya āhavanīyaḥ | / ainaṃ catvāri vāmāni gacchanti niṣkaḥ kaṃso 'śvataro hasty / adhipatiḥ (…) || see 1e

„‚Allträger‘ heißen diese Wasser, nämlich der Mensch. / Ihr Herr ist Mṛtyu [der Tod]. / Wer diese Allträger-Wasser kennt, Mṛtyu als Herrn: / er wird Träger des Alls, das All trägt ihn. / In seinem Haus werden drei Feuer gesetzt: das Dakṣiṇa-, das Gārhapatya-, das Āhavanīya-Feuer. / Zu ihm kommen vier Güter: Halsschmuck, Bronze[gefäß], Maultier, Elefant. / (Er wird Herr über die Seinen und die anderen, wer so weiß.)“

Vers 11.16.14

tāsāṃ vā etāsām apāṃ himavān ūdhaḥ somo vatsaḥ parameṣṭhy adhipatiḥ | / yo vā etāsām apāṃ himavantam ūdhaḥ somaṃ vatsaṃ parameṣṭhinam adhipatiṃ veda | / parameṣṭhī bhavati gacchati parameṣṭhitām / adhipatir bhavati svānāṃ cānyeṣāṃ ca ya evaṃ veda ||

„Von diesen Wassern nun ist der Himavant [Himalaya] das Euter, Soma das Kalb, Parameṣṭhin der Herr. / Wer von diesen Wassern den Himavant als Euter, Soma als Kalb, Parameṣṭhin als Herrn kennt: / er wird Parameṣṭhin [Höchststehender], erreicht die Höchststellung, / er wird Herr über die Seinen und die anderen, wer so weiß.“
