Paippalāda-Saṃhitā · Kāṇḍa 7

Hymne 7.5 Amulett gegen Schadenzauber (Aśvattha-Maṇi)

Vers 7.5.1

vaiśvānarād arocata / jāto hiraṇyayo maṇiḥ | / tam ābharad bṛhaspatiḥ / kaśyapo vīryāya kam ||

Aus Vaiśvānara strahlte es auf, / geboren, das goldene Amulett. / Das brachte Bṛhaspati, Kaśyapa, / zur Kraft, zum Wohl.

Vers 7.5.2

bṛhaspatis tam akṛṇon / maṇiṃ vaiśvānaraṃ sahaḥ | / saptarṣayo balāya kaṃ / saṃ dadhuṣ ṭvā vayodhasaḥ ||

Bṛhaspati machte dieses Amulett / zur Vaiśvānara-Stärke. / Die sieben Ṛṣis fügten dich zusammen für die Kraft, / dich, den Lebensgeber.

Vers 7.5.3

viśve devās ta indriyaṃ / saptarṣayaś ca saṃ dadhuḥ | / jāto hiraṇyayo maṇir / agner vaiśvānarād adhi ||

Alle Götter und die sieben Ṛṣis / fügten dir die Indra-Kraft zusammen: / geboren das goldene Amulett / aus Agni Vaiśvānara.

Vers 7.5.4

aśvattho jātaḥ prathamo / 'gneḥ priyatamā tanūḥ | / vaiśvānarasya sṛṣṭyā / kṛtyādūṣiḥ kṛto maṇiḥ ||

Der Aśvattha wurde als erster geboren, / Agnis liebster Leib. / Durch Vaiśvānaras Schöpfung / wurde das Amulett zum Kṛtyā-Verderber gemacht.

Vers 7.5.5

kṛtyādūṣiṃ tvāvidaṃ / kṛtyādūṣiṃ bharāmi tvā | / kṛtyādūṣiṃ kṛṇomi tvā / kṛtyādūṣiṃ vayodhasam ||

Als Kṛtyā-Verderber habe ich dich gefunden, / als Kṛtyā-Verderber bringe ich dich, / als Kṛtyā-Verderber mache ich dich, / als Kṛtyā-Verderber, Lebensgeber.

Vers 7.5.6

patatrī pakṣī balavān / kṛtyādūṣiḥ sapatnahā | / nitatnir viśvabheṣaja / ugra āpatiko maṇiḥ ||

Geflügelt, ein Vogel, kraftvoll, / Kṛtyā-Verderber, Feindtöter; / Nitatni, Allheilmittel, / furchtbar, Āpatika [?], das Amulett.

Vers 7.5.7

patatrī te balāya kaṃ / nitatnir bheṣajāya te | / jāto hiraṇyayo maṇir / apa rakṣāṃsi sedhatu ||

Der Geflügelte [sei] dir zur Kraft, / der Nitatni dir zur Heilung; / das geborene goldene Amulett / soll die Rakṣas vertreiben.

Vers 7.5.8

devo maṇiḥ sapatnahā / rakṣohāmīvacātanaḥ | / hiraṇyayonir aṃśumān / kaśyapenābhṛtaṃ sahaḥ ||

Göttliches Amulett, Feindtöter, / Rakṣas-Töter, Vertreiber der Krankheiten, / goldschößig, strahlenreich: / die von Kaśyapa gebrachte Kraft.

Vers 7.5.9

vaiśvānaraṃ tejanam ekam āhur / agner yoneḥ saha candreṇa jātam | / gayasphānaḥ prataraṇo vayodhāḥ / kṛtyādūṣir valagahāsy ugraḥ ||

Ein Vaiśvānara-Tejana [Schärfe/Rohr?] [?], sagen sie, [ist] eines, / aus Agnis Schoß mit dem Mond geboren; / Haus-Mehrer, Hinüberbringer, Lebensgeber, / Kṛtyā-Verderber, Valaga-Töter bist du, furchtbar.

Vers 7.5.10

yasyedaṃ bhūmyām adhi / nikrāntaṃ pāṃsure padam | / mṛjānas tanvo yad rapas / tasya snāhi tanū adhi ||

Dessen Fußtritt hier auf der staubigen Erde / eingetreten ist — / abwischend, was am Körper Schaden ist [?], / davon bade dich am Leib.

Vers 7.5.11

dūṣyās tvā vadhaṃ vayaṃ / devasya savituḥ save | / jīvātave bharāmasi / mahyā ariṣṭatātaye ||

Dich, den Tod [Waffe] der Verhexung, / tragen wir auf des Gottes Savitar Antrieb / zum Leben, / für mich zur Unversehrtheit.

Vers 7.5.12

ācchedanaḥ pracchedano / dviṣatas tapano maṇiḥ | / śatruñjayaḥ sapatnahā / dviṣantam apa bādhatām ||

Der Abreißer, der Abschneider, / der die Hasser Erhitzende, das Amulett, / Feindbesieger, Nebenbuhler-Töter: / den Hasser soll er abdrängen.
