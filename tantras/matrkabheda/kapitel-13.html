Mātṛkābhedatantra

Paṭala 13: Mātṛkābhedatantra, trayodaśaḥ paṭalaḥ Paṭala 13: Rosenkranz-Materialien nach Gottheit und Knotentechnik der Mālā, Fehler-Diagnostik und Sühne-Riten

Katalog der Rosenkranz-Materialien (Mālā) nach Zielgottheit (Tulasī, Elfenbein, Rudrākṣa, Mahāśaṅkha, Bergkristall, Koralle, Edelmetall, Stechapfelsamen), Vorschriften zur Knotentechnik (Brahma-Knoten, ,Schlangenfessel', Meru-Perle), eine Fehler-Diagnostik ritueller Störungen beim Rezitieren (Zittern, Schütteln, Geräusch, Herabfallen, Zerreißen der Schnur) mit jeweiligen Unglücksfolgen, sowie die zugehörigen Sühne-Riten (Guru-Einladung, Homa, Puraścaraṇa).

Vers 13.1-13.7

Mātṛkābhedatantra, trayodaśaḥ paṭalaḥ / śrīcaṇḍikovāca / śṛṇu nātha parānanda parāparajagatpate / idānīṃ śrotum icchāmi mālāyāḥ kīdṛśo japaḥ / kā mālā kasya devasya tad vadasva samāhitaḥ // MBhT_13.1 // śrīśaṃkara uvāca / vaiṣṇave tulasīmālā gajadantair gaṇeśvare / kālikāyā mahāmantraṃ japed rudrākṣamālayā // MBhT_13.2 // tārāyāś ca japen mantrī mahāśaṅkhākhyamālayā / mahāśaṅkhākhyamālāyāṃ sarvāṃ vidyāṃ japet sudhīḥ // MBhT_13.3 // akasmād vai mahāsiddhir mahāśaṅkhākhyamālayā / tathaiva sakalā vidyā mahāśaṅkhe vaset sadā // MBhT_13.4 // sphāṭikī sarvadevasya pravālaiḥ sakalāṃ japet / svarṇaraupyasamudbhūtāṃ sarvadeveṣu yojitām // MBhT_13.5 // kālikāyāś ca sundaryā rudrākṣaiḥ prajapet sadā / bhairavyāḥ prajapen mantrī śaṅkhapadmākhyayā priye // MBhT_13.6 // śmaśāne dhusturair mālā japed dhūmāvatīvidhau / iti te kathitaṃ kānte mahāmālāvinirṇayam // MBhT_13.7 //

Mātṛkābhedatantra, dreizehnter Paṭala. Śrī Caṇḍikā sprach: „Höre, o Herr, [du] höchste Wonne, Herr der höheren und niederen Welt! Jetzt möchte ich hören, wie die Rezitation mit der Rosenkranz-Schnur (Mālā) beschaffen ist – welche Rosenkranz-Schnur zu welcher Gottheit gehört; das sage mir, gesammelten Sinnes.“ Śrī Śaṃkara sprach: „Für den Viṣṇu-Kult [gilt] die Tulasī-Rosenkranz-Schnur, beim Herrn der Scharen (Gaṇeśa) eine [Schnur] aus Elefantenzähnen; den großen Mantra der Kālikā rezitiere man mit einer Rudrākṣa-Rosenkranz-Schnur. Und [den Mantra] der Tārā rezitiere der Mantra-Kundige mit der sogenannten ,Großmuschel'-Rosenkranz-Schnur; mit der ,Großmuschel'-Rosenkranz-Schnur rezitiere der Kluge jedes [Mantra-]Wissen. Durch die ,Großmuschel'-Rosenkranz-Schnur entsteht unversehens eine große Siddhi; ebenso wohne jedes [Mantra-]Wissen stets in der Großmuschel. Die Bergkristall-Schnur [dient] für jede Gottheit, mit Korallen rezitiere man das gesamte [Wissen]; die aus Gold und Silber entstandene [Schnur] ist bei allen Gottheiten einzusetzen. Und [den Mantra] der Kālikā [und] der Sundarī rezitiere man stets mit Rudrākṣa[-Beeren]; [den Mantra] der Bhairavī rezitiere der Mantra-Kundige mit der sogenannten ,Muschel-Lotos'-Schnur, o Liebste. Auf dem Kremationsplatz rezitiere man mit einer Rosenkranz-Schnur aus Stechapfelsamen beim Ritual der Dhūmāvatī. So wurde dir, o Geliebte, die endgültige Entscheidung über die großen Rosenkranz-Schnüre mitgeteilt.“

Dreizehnter Paṭala: Katalog der Rosenkranz-Materialien (Mālā) nach Zielgottheit – Tulasī (Basilikum) für Viṣṇu, Elfenbein für Gaṇeśa, Rudrākṣa für Kālikā/Sundarī, ,Großmuschel' (Mahāśaṅkha) für Tārā und allgemein universell wirksam, Bergkristall/Koralle/Edelmetall für beliebige Gottheiten, Stechapfelsamen (Dhustūra, eine giftige, halluzinogen wirkende Pflanze) für das Kremationsplatz-Ritual der Dhūmāvatī (einer der zehn Mahāvidyās, ikonographisch mit Witwenschaft/Unglück assoziiert) – Beleg für die systematische Materialsymbolik tantrischer Ritualpraxis.

Vers 13.8-13.14

atha granthiṃ pravakṣyāmi śṛṇu kānte samāhitā / yena mālā susiddhā ca nṇāṃ sarvaphalapradā // MBhT_13.8 // mālāyāś cādhikā kānte granthiś caikā phalapradā / ekapañcāśikāyāṃ ca mālāyāṃ parameśvari // MBhT_13.9 // brahmagranthiyutāṃ mālāṃ sārdhadvitayaveṣṭitām / sapādaveṣṭanaṃ devi nāgapāśaṃ manoharam // MBhT_13.10 // sarvadevasya mālāyāṃ sarvatra parameśvari / brahmagranthiṃ vidhāyetthaṃ nāgapāśam athāpi vā // MBhT_13.11 // mālāyāṃ tv adhikāṃ devi caikāṃ granthiṃ pradāpayet / mūlena grathitaṃ kuryāt praṇavenāthavā priye // MBhT_13.12 // granthimadhye ca guṭikāṃ kuryād atimanoharām / sūtradvayaṃ maheśāni milanaṃ kārayet tataḥ // MBhT_13.13 // meruṃ ca grathanaṃ kuryāt tadūrdhve granthisaṃyutam / evaṃ mālāṃ vinirmāya gopayed bahuyatnataḥ // MBhT_13.14 //

Nun will ich über den Knoten sprechen; höre, o Geliebte, gesammelten Sinnes, wodurch die Rosenkranz-Schnur wohl-vollendet und den Menschen jede Frucht gewährend wird. Und, o Geliebte, ein zusätzlicher Knoten an der Rosenkranz-Schnur gewährt eine [besondere] Frucht – [dies gilt] bei einer Rosenkranz-Schnur aus einundfünfzig [Perlen], o höchste Herrin. Man [fertige] die Rosenkranz-Schnur versehen mit einem Brahma-Knoten, zweieinhalbfach umwickelt [?]; mit einer Umwicklung von eineinviertelfacher [Länge, ?], o Göttin, [wird sie zur] bezaubernden ,Schlangenfessel' (Nāgapāśa). Bei der Rosenkranz-Schnur für jede Gottheit [verfahre man] überall, o höchste Herrin, indem man so den Brahma-Knoten anlegt, oder auch die ,Schlangenfessel'. An der Rosenkranz-Schnur aber lege man, o Göttin, einen zusätzlichen einzelnen Knoten an; man verknüpfe [ihn] mit dem Wurzelmantra oder mit der Silbe Praṇava (Oṃ), o Liebste. Und in der Mitte des Knotens fertige man eine sehr bezaubernde Perle (Guṭikā); die beiden Schnurenden lasse man dann, o große Herrin, zusammentreffen. Und man knüpfe den Meru [die Hauptperle], darüber mit einem Knoten versehen; nachdem man so die Rosenkranz-Schnur fertiggestellt hat, hüte man sie mit großer Sorgfalt.

Die genauen Maßangaben ,sārdhadvitaya' (,zweieinhalbfach') und ,sapāda' (,eineinviertelfach', V.10) für die Knotenumwicklung der ,Schlangenfessel'-Mālā bleiben in ihrer technischen Anwendung unsicher [?] und wurden wörtlich übersetzt. Der ,Meru' (V.14) bezeichnet die traditionelle Hauptperle am Ende einer Rosenkranz-Schnur (auch ,Sumeru' genannt), an der beim Zählen umgekehrt wird – benannt nach dem kosmischen Weltenberg.

Vers 13.15-13.20

kampanaṃ dhūnanaṃ śabdaṃ naiva tatra prakāśayet / karabhraṣṭaṃ tathā chinnaṃ mahāvighnasya kāraṇam // MBhT_13.15 // kampane siddhihāniḥ syād dhūnanaṃ bahuduḥkhadam / śabde jāte bhaved rogaḥ karabhraṣṭād vināśakṛt // MBhT_13.16 // chinnasūtre bhaven mṛtyus tasmād yatnaparo bhavet / evaṃ jñātvā maheśāni śāntisvastyayanaṃ caret // MBhT_13.17 // kampane yo japen mantraṃ yadi siddhiṃ prayacchati / yatnena gurum ānīya dvāviṃśadupacārataḥ // MBhT_13.18 // kumbhasthāpanakaṃ kṛtvā pūjayed iṣṭadevatām / tato huned bilvapattrair aṣṭottaraśatāhutim // MBhT_13.19 // trimadhvaktena vidhinā dhūnane 'pi ca sundari / saśabde japane caṇḍi hy evaṃ kuryād vicakṣaṇaḥ // MBhT_13.20 //

Zittern, Schütteln [und] Geräusch [der Perlen] lasse man dabei keineswegs zutage treten; ebenso ist ein Herabfallen aus der Hand oder ein Zerreißen [der Schnur] Ursache eines großen Hindernisses. Bei Zittern [der Schnur] entstünde ein Verlust der Siddhi; Schütteln bringt vielfaches Leid; entsteht ein Geräusch, so entsteht Krankheit; durch Herabfallen aus der Hand entsteht Vernichtung. Bei zerrissener Schnur entstünde der Tod; deshalb sei man eifrig auf Sorgfalt bedacht. Dies wissend, o große Herrin, vollziehe man ein Friedens- und Segensritual (Śānti-Svastyayana). Wer, wenn [die Schnur] zittert, dennoch den Mantra rezitiert – falls er [gleichwohl] eine Siddhi erlangen will [Anm.: Lesart unsicher, wörtlich ,falls es Siddhi gewährt'] –, der hole mit Sorgfalt den Guru herbei [und verehre ihn] mit zweiundzwanzigfachem Opferdienst; nachdem er die Kumbha-Aufstellung vollzogen hat, verehre er die gewünschte Gottheit; danach opfere er im Feuer mit Bilva-Blättern hundertundacht Oblationen, nach der Vorschrift mit den drei süßen [Substanzen] Beträufelten – auch bei [dem Fehler des] Schüttelns, o Schöne; und bei Geräusch während der Rezitation, o Caṇḍī, verfahre der Kluge ebenso.

V.18 (,yadi siddhiṃ prayacchati') ist syntaktisch unsicher [?] – wörtlich ,falls es Siddhi gewährt'; hier als konzessive Fortsetzung interpretiert, die in einen fortlaufenden Sühne-Ritus für den Kampana-Fehler übergeht (V.18-20: Guru-Einladung, Kumbha-Aufstellung, Pūjā, 108-facher Bilva-Homa mit Trimadhu-Beträufelung). Das ,Trimadhu' (,dreifach Süßes', V.20) bezeichnet vermutlich eine Mischung aus Honig, Ghee und Zucker bzw. Milch, ein verbreitetes Substrat tantrischer Homa-Rituale; die genaue Zusammensetzung bleibt [?].

Vers 13.21-13.25

karabhraṣṭe tathā chinne puraścaraṇam ācaret / japādyante yajed devīṃ ṣoḍaśair upacārakaiḥ // MBhT_13.21 // pratyahaṃ prajapen mantraṃ pratyahaṃ balidānakam / pañcāṅgasya pramāṇena sarvakarma samāpayet // MBhT_13.22 // daridraḥ parameśāni yadi vighnaparāyaṇaḥ / ādyante mahatīṃ pūjāṃ diksahasraṃ japen manum // MBhT_13.23 // sahasraikaṃ hunet paścāt sarvavighnasya śāntaye / kumbhatoyaiḥ snāpayitvā punar mālāṃ pradāpayet // MBhT_13.24 // anenaiva vidhānena vighnajālair na lipyate // MBhT_13.25 //

Bei [dem Fehler des] Herabfallens aus der Hand sowie bei Zerreißen [der Schnur] vollziehe man ein Puraścaraṇa (vorbereitende Wiederholungsbuße); am Ende der Rezitation verehre man die Göttin mit sechzehnfachem Opferdienst. Täglich rezitiere man den Mantra, täglich [bringe man] eine kleine Opfergabe dar; nach dem Maß des Fünfgliedrigen (Pañcāṅga [?]) vollende man jedes rituelle Werk. Ist [der Praktizierende] arm, o höchste Herrin, [oder] den Hindernissen ausgeliefert, [so] vollziehe er am Anfang und Ende eine große Verehrung [und] rezitiere den Mantra zehntausendmal (Dik-Sahasram). Danach opfere er tausendundeinmal im Feuer, zur Befriedung jedes Hindernisses; nachdem er [die Schnur] mit dem Wasser des [geweihten] Kumbha-Topfes gebadet hat, übergebe (weihe) er die Rosenkranz-Schnur erneut. Eben durch diese Vorschrift wird man nicht von Hindernis-Netzen befleckt.

Dreizehnter Paṭala damit abgeschlossen. ,Diksahasram' (V.23) folgt der schon in Paṭala 9 belegten Bhūtasaṃkhyā-Konvention (,diś' = zehn Himmelsrichtungen mal ,sahasra' = 1000 = 10.000). ,Pañcāṅga' (V.22, wörtl. ,Fünfglied') bezeichnet vermutlich die fünfteilige Grundstruktur eines Sādhana-Rituals, bleibt hier aber ohne nähere Spezifikation [?].
