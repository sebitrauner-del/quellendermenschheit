Mātṛkābhedatantra

Paṭala 1: Mātṛkābhedatantra, prathamaḥ paṭalaḥ Paṭala 1: Alchemistische Grundlagen – Edelmetall-Transmutation und Wein-Reinigung

Eröffnungsrahmen (Dialog Bhairava/Caṇḍikā auf dem Kailāsa) und sogleich eine praktisch-alchemistische Unterweisung: Herstellung eines quecksilberbasierten Reagens zur Verwandlung von Kupfer in Silber (V.5-16), Herstellung der dazugehörigen borax-basierten "Milch-Form" (V.17-20), und eine kodierte Bīja-Mantra-Formel zur Geruchsreinigung von Wein (V.21-23). Charakteristisch für die spätere, praxisorientierte Tantra-Literatur, die rituelle Verehrung eng mit angewandter Alchemie (Rasaśāstra) verknüpft.

Vers 1.1-1.4

kailāsaśikhare ramye nānāratnopaśobhite / papraccha parayā bhaktyā bhairavaṃ parameśvaram // MBhT_1.1 // śrīcaṇḍikovāca / tripurāpūjanaṃ nātha svarṇaratnair viśeṣataḥ / kalikāle svarṇarūpyaṃ guptabhāvaṃ tathā maṇim // MBhT_1.2 // kenopāyena deveśa svarṇarūpyādi labhyate / tad vadasva viśeṣeṇa yathā ratnādikaṃ bhavet // MBhT_1.3 // yan noktaṃ sarvatantreṣu tad vadasva dayānidhe // MBhT_1.4 //

Auf dem lieblichen Gipfel des Kailāsa, geschmückt mit mancherlei Juwelen, befragte [Caṇḍikā] mit höchster Hingabe Bhairava, den höchsten Herrn. Śrī Caṇḍikā sprach: „O Herr, [was] die Verehrung der Tripurā [betrifft], besonders mit Gold und Juwelen – im Kali-Zeitalter, Gold, Silber, und ebenso einen geheimnisvoll [alchemisch hergestellten] Edelstein – durch welches Mittel, o Gebieter der Götter, werden Gold, Silber usw. erlangt? Sage das im Einzelnen, wie ein Edelstein u.a. entsteht. Was in allen [anderen] Tantras nicht gesagt wurde, das sage mir, o Schatz des Mitleids.“

Eröffnungsrahmen des Werks (Dialogform Bhairava–Caṇḍikā auf dem Kailāsa, wie bei den meisten Tantras). Das Werk beginnt untypisch nicht mit einer Anrufung, sondern direkt mit einer alchemistisch-rasaśāstrischen Frage (Goldgewinnung für die Tripurā-Verehrung) – Mātṛkābhedatantra gehört damit zu einer Gruppe später tantrischer Texte, die rituelle Alchemie (rasāyana) und Göttinnenverehrung eng verknüpfen.

Vers 1.5-1.8

śrīśaṅkara uvāca / śṛṇu devi pravakṣyāmi yathā ratnādikaṃ bhavet / mattejasā pāradena kiṃ ratnaṃ na hi labhyate // MBhT_1.5 // tathā sāmudrakeṇaiva suśubhralavaṇena ca / sambalasya prakāraṃ hi śṛṇu devi prayatnataḥ // MBhT_1.6 // cīnatantrānusāreṇa pūjayet siddhakālikām / athavā pūjayed devīṃ dakṣiṇāṃ kālikāṃ parām / kālītantroktavidhinā saptāhaṃ japapūjanam // MBhT_1.7 // satye caikaṃ tu tretāyāṃ dviguṇaṃ dvāpare trayam / evaṃ sarvatra jānīyāc caturguṇajapaḥ kalau // MBhT_1.8 //

Śrī Śaṅkara sprach: „Höre, Göttin, ich will verkünden, wie ein Edelstein u.a. entsteht. Durch mit [meiner] Kraft erfülltes Quecksilber [Pārada] – welcher Edelstein wäre da nicht erlangbar? Ebenso mit reinem, glänzend-weißem Meersalz – höre, Göttin, mit Sorgfalt die Art des [alchemischen] Reagens. Gemäß dem Cīna-Tantra [der ‚chinesischen' Überlieferung] verehre man die Siddha-Kālikā, oder man verehre die Göttin, die höchste Dakṣiṇā-Kālikā, sieben Tage lang mit Mantra-Wiederholung und Verehrung nach der im Kālī-Tantra gelehrten Vorschrift. Im Satya[-Zeitalter genügt] eine [Wiederholung], in der Tretā das Doppelte, im Dvāpara das Dreifache – so wisse man überall: im Kali [ist] die Mantra-Wiederholung vierfach.“

Der Sprecher wird ab hier durchgehend als „Śrī Śaṅkara“ (Śiva) bezeichnet, während die Fragende als „Śrī Caṇḍikā“ auftritt – ein für Śākta-Tantras typisches Dialogpaar (Bhairava/Caṇḍikā = Śiva/Devī). Der Verweis auf ein „Cīnatantra“ (,chinesisches Tantra') ist ein bekanntes Motiv später tantrischer Texte, die bestimmte (v.a. kaula-vāmācāra-artige) Praktiken auf eine exotische, ferne Herkunft zurückführen.

Vers 1.9-1.13

ānīya bahuyatnena sambalaṃ toladvayam / vasur ādyaṃ śivaṃ cādyaṃ māyābinduvibhūṣitam / bījatrayaṃ cāṣṭaśataṃ prajapet sambalopari // MBhT_1.9 // aśītitolakaṃ mānaṃ kṛṣṇadhenusamudbhavam / dugdham ānīya yatnena cāṣṭottaraśataṃ japet // MBhT_1.10 // vastrayuktena sūtreṇa dugdhamadhye vinikṣipet / uttāpaṃ janayed dhīmān mandamandena vahninā // MBhT_1.11 // bindu vedāntaparyantam ardhaśoṣaṃ bhaved yadā / tadaivottolya tad dravyaṃ toyamadhye vinikṣipet // MBhT_1.12 // tataḥ parīkṣā kartavyā pradadyāt pāvakopari / nirdhūmaṃ vāvake dravyaṃ dṛṣṭvā utthāpya yatnataḥ // MBhT_1.13 //

Nachdem man mit großer Mühe das Reagens [Sambala], zwei Tola [an Gewicht], beschafft hat – [rezitiere man das aus] Vasu zuerst, Śiva zuerst [gebildete, mit dem Nasalierungszeichen Māyā-Bindu geschmückte Keimsilben-Mantra] –, wiederhole man den dreifachen Keimsilben-Mantra hundertundacht Mal über dem Reagens. [Dann,] nachdem man, im Maß von achtzig Tola, Milch von einer schwarzen Kuh sorgfältig beschafft hat, wiederhole man [den Mantra] hundertundacht Mal. Mittels eines mit Tuch versehenen Fadens tauche man [das Reagens] in die Milch; der Kundige erzeuge Hitze mit ganz sanftem Feuer. Wenn der Tropfen [des Stoffes], bis zur Stufe „Vedānta“ [?, alchemischer Fachbegriff unklar], halb eingetrocknet ist, dann hebe man den Stoff sogleich heraus und lege ihn ins Wasser. Danach ist die Prüfung vorzunehmen: man lege [den Stoff] über das Feuer; sobald man sieht, dass der Stoff im Feuer rauchfrei ist, hebe man ihn sorgfältig heraus.

Technisch-alchemistische (rasaśāstra-artige) Verfahrensanweisung zur Herstellung eines Quecksilber-Reagens, verbunden mit ritueller Mantra-Wiederholung (108- bzw. 8-fach). Der Begriff „vedāntaparyantam“ (V.12) ist als alchemischer Fachterminus für eine bestimmte Trocknungs-/Reifestufe des Präparats nicht sicher zu identifizieren [?] und daher wörtlich-transliteriert belassen; ebenso bleibt die genaue Bedeutung des Keimsilben-Mantras („vasur ādyaṃ śivaṃ cādyam“) in V.9 als kodierte Bīja-Formel unaufgelöst [?] – solche Verschlüsselungen sind in tantrischer Mantraśāstra-Literatur üblich und nur mit spezialisiertem Kommentarwissen sicher zu entschlüsseln.

Vers 1.14-1.16

tatraiva prajapen mantraṃ sarvavandyanavātmakam / ānīya bahuyatnena śuddhaṃ tāmraṃ manoharam // MBhT_1.14 // sārdhena tolakaṃ tāmraṃ vahnimadhye vinikṣipet / yathā vahnis tathā tāmraṃ dṛṣṭvā utthāpya yatnataḥ // MBhT_1.15 // guñjāpramāṇaṃ tad dravyaṃ tatkṣaṇād yadi yojayet / satyaṃ satyaṃ hi girije raupyaṃ bhavati niścitam // MBhT_1.16 //

Ebendort wiederhole man den aus neun, von allen verehrten [Silben bestehenden] Mantra. Nachdem man mit großer Mühe reines, schönes Kupfer beschafft hat, lege man anderthalb Tola Kupfer ins Feuer; sobald man sieht, dass das Kupfer wie das Feuer selbst [glüht], hebe man es sorgfältig heraus. Wenn man jenen Stoff, im Maß eines Guñjā-Samens, sogleich [mit dem Kupfer] vereinigt – wahrlich, wahrlich, o Tochter des Berges, wird es gewiss zu Silber.

„Guñjā“ ist das traditionelle kleine Gewichtsmaß nach dem Samen der Abrus-precatorius-Pflanze (Paternostererbse), in der indischen Alchemie/Medizin gebräuchlich für sehr geringe Mengen. Die feierliche Beteuerungsformel „satyaṃ satyaṃ“ (,wahrlich, wahrlich') markiert den Abschluss eines alchemischen Verfahrens-Abschnitts und kehrt im Werk mehrfach wieder.

Vers 1.17-1.20

śrīcaṇḍikovāca / kāraṇaṃ dugdharūpaṃ vā kena rūpeṇa śaṅkaraḥ / tatprakāraṃ mahādeva kṛpayā vada śaṅkara // MBhT_1.17 // śrīśaṅkara uvāca / ṭaṅkanam ānayed dhīmān tolakaṃ tu catuṣṭayam / vahniyogena girije lājarūpaṃ cakāra ha // MBhT_1.18 // āmrapuṣpaṃ tad dviguṇaṃ piṣṭvā milanam ācaret / tasyopari japen mantraṃ mahāmāyāṃ hi caṇḍike // MBhT_1.19 // etat tu guṭikāṃ kṛtvā melanaṃ kārayed yadi / tadaiva dugdharūpaṃ syāt satyaṃ satyaṃ hi śailaje // MBhT_1.20 //

Śrī Caṇḍikā sprach: „In welcher Form, o Śaṅkara, [entsteht] das Reagens [Kāraṇa], oder seine ‚Milch-Form'? Diese Art, o Großer Gott, sage aus Mitleid, Śaṅkara.“ Śrī Śaṅkara sprach: „Der Kundige beschaffe Borax [Ṭaṅkana], vier Tola; durch Anwendung von Feuer, o Tochter des Berges, mache man [ihn] zur Form von geröstetem Korn [Lāja]. Nachdem man Mangoblüte, das Doppelte davon, zermahlen hat, vollziehe man die Vermengung; darüber wiederhole man den Mahāmāyā-Mantra, o Caṇḍikā. Wenn man dies aber zu einer Kugel geformt hat und die Vermengung durchführt, dann entsteht sogleich die ‚Milch-Form' – wahrlich, wahrlich, o Tochter des Bergherrn.“

„Ṭaṅkana“ (Borax, Natriumborat) ist ein Standardreagens der klassischen indischen Alchemie/Rasaśāstra-Tradition, hier mit „Lāja“ (geröstetes/gepufftes Korn) hinsichtlich seiner physischen Umwandlungsform verglichen.

Vers 1.21-1.23

śrīcaṇḍikovāca / gandhahīnaṃ bhaven madyaṃ kenopāyena śaṅkara / tat sarvaṃ śrotum icchāmi yadi sneho 'sti mā prati // MBhT_1.21 // śrīśaṅkara uvāca / śivaṃ vahnisamārūḍhaṃ vāmanetravibhūṣitam / bindunādasamāyuktaṃ gandham ādāya saṃlikhet // MBhT_1.22 // uhyatāṃ padam uccāryaṃ cāṣṭottaraśataṃ yadi / prajapet sādhakaśreṣṭho durgandhādivināśanam // MBhT_1.23 //

Ein weiteres Beispiel kodierter Bīja-Mantra-Konstruktion nach dem klassischen tantrischen Verfahren, Keimsilben über ikonographisch-symbolische Umschreibungen (,Śiva', ,Feuer', ,linkes Auge', ,Bindu', ,Nāda') anzudeuten, statt sie offen zu nennen – ihre exakte lautliche Gestalt bleibt ohne Kommentar-Tradition nicht mit Sicherheit rekonstruierbar [?]. Auch das explizit als Rezitationswort genannte „uhyatām“ (wörtl. etwa ,es werde verborgen/getragen', 3.Sg.Passiv-Imperativ von √vah oder √guh) bleibt in seiner rituellen Funktion unsicher [?]. Mit V.23 endet der erste Paṭala, der ganz der alchemistisch-magischen Grundausstattung (Edelmetall-Transmutation, Wein-Reinigung) gewidmet ist – ein für spätere, praxisorientierte Tantras charakteristischer Einstieg vor den in Paṭala 2 folgenden Themen der Kuṇḍalinī-Physiologie.
