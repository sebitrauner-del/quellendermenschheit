Mātṛkābhedatantra

Paṭala 9: Mātṛkābhedatantra, navamaḥ paṭalaḥ Paṭala 9: Bhasma-Alchemie – Ausführenden-Weihe, Homa-Kuṇḍa, Quecksilber-Verzehr-Rituale und das Viśveśvara-Verfahren

Ein weiteres Bhasma(Asche)-Alchemie-Kapitel, thematisch parallel zu Paṭala 5, jedoch mit eigener Substanz und Prozedur: Auswahl und Schmückung eines rituellen Ausführenden, Homa-Kuṇḍa-Bau und -Vollzug, ein Ritual des Quecksilber-Verzehrs zusammen mit Muttermilch und dem Verbrennen eines 'neuntorigen Kalbs', sowie das abschließende Viśveśvara-Verfahren (Quecksilber-Schwefel-Präparat gegen Hautaussatz) samt eindringlicher Warnung vor unqualifizierter Anwendung.

Vers 9.1-9.5

Mātṛkābhedatantra, navamaḥ paṭalaḥ / śrīśiva uvāca / bhasmaprakāraṃ deveśi śṛṇu matprāṇavallabhe / kartāraṃ varayed ādau yathoktavibhavāvadhi // MBhT_9.1 // suvarṇaṃ mauktikayutaṃ karṇayugme nivedayet / hastayugme ca valayam aṅgurīyaṃ tathaiva ca // MBhT_9.2 // toḍhadvayaṃ bāhuyugme śuddhakāñcananirmitam / grīvāyāṃ dāpayet svarṇaṃ catuṣkoṇaṃ manoramam // MBhT_9.3 // vastrayugmaṃ paṭṭasūtranirmitaṃ ca suśobhanam / uṣṇīṣaṃ śuklavarṇaṃ ca uṣṇīṣaṃ pītavāsasam // MBhT_9.4 // evaṃ hi varayed devi karmayogyaṃ vicintayet / cintayec chivarūpaṃ ca cintayet triguṇātmakam // MBhT_9.5 //

Mātṛkābhedatantra, neunter Paṭala. Śrī Śiva sprach: „Höre, o Herrscherin der Götter, die Art der Bhasma[-Herstellung], o Geliebte meines Lebens: zuerst wähle man den Ausführenden entsprechend dem zuvor genannten Vermögensumfang. Gold, mit Perlen versehen, biete man für das Ohrenpaar dar; für das Händepaar einen Armreif und ebenso einen Ring. Ein Paar Armbänder [Toḍha] für das Armpaar, aus reinem Gold gefertigt; für den Hals gebe man Gold, vierseitig und lieblich. Ein Gewandpaar, aus Seidenband gefertigt und wohlgestaltet; einen weißfarbenen Turban und einen Turban mit gelbem Gewand [Anm.: ,uṣṇīṣaṃ pītavāsasam', wörtl. ,Turban [mit] gelbem Gewand' – wohl zwei getrennte Kleidungsstücke gemeint]. So wähle man [ihn], o Devī, [und] betrachte [ihn als] für das Werk geeignet; man meditiere über die Śiva-Gestalt und meditiere über [ihn als] aus den drei Guṇas bestehend.“

Neunter Paṭala: ein weiteres Bhasma(Asche)-Alchemie-Kapitel, thematisch parallel zu Paṭala 5, doch mit anderer Substanz/Prozedur – zunächst die Auswahl und rituelle Schmückung eines Ausführenden, ganz analog zur Liṅga-Weihe in Paṭala 8.

Dann, am folgenden Tag, vollziehe man ein Friedens- und Segensritual, mit reinem Gold gefertigt, mit Bilva-Blättern, Schöne. Mit der Zahl Tausend verehre man, o Devī, die zwölf erdenen [Bildnisse], mit dem sechzehnfachen Opferdienst und mit einem Paar Seidengewändern. Mit mannigfaltigem Schmuck verehre man den höchsten Herrn; genussgerechte [Gaben] sind darzureichen, Madhuparka biete man dar. Nachdem man [sie] auf einen goldenen Sitz gestellt hat, vollziehe man einzeln die Verehrung; am Ende der Verehrung rezitiere der Weise den Mantra hundertundacht Mal. Den sechssilbigen großen Mantra, dann den ,Prāsāda' genannten Manu; man rezitiere den Mantra tausendfach in [alle] Richtungen [Anm.: ,diksahasram', Sinn unsicher, evtl. richtungsbezogene tausendfache Rezitation; derselbe Begriff bereits in Paṭala 3 unsicher], und opfere dessen Zehntel im Feueropfer, Geliebte.

Vers 9.11-9.17

homasya dravyaṃ deveśi śṛṇu matprāṇavallabhe / vālukānirmite vāpi kuṇḍe vā parameśvari // MBhT_9.11 // dvātriṃśadaṅgulimānaṃ vistṛtaṃ tatsamaṃ priye / ṣoḍaśāṅgulimānaṃ hi kuṇḍaṃ kuryāt sulakṣaṇam // MBhT_9.12 // tadūrdhve parameśāni vedanetrāṅguliṃ śive / eva hi svarṇakumbhaṃ ca tāmrakumbhāsamarthinā // MBhT_9.13 // etad anyataraṃ kumbhaṃ sthāpayed vedikopari / paṭṭavastreṇa yugmena saṃveṣṭya bahuyatnataḥ // MBhT_9.14 // homayed bilvapattreṇa yathoktena sureśvari / trimadhvaktena vidhinā tataḥ siddho bhaved dhruvam // MBhT_9.15 // tatas tu dakṣiṇā kāryā yathoktavibhavāvadhi / sarvadravyamayaṃ mūlyaṃ dviguṇaṃ vā pradāpayet // MBhT_9.16 // dakṣiṇāvihīnā yajñāḥ siddhidā na ca mokṣadāḥ / ata eva maheśāni dakṣiṇā vibhavāvadhi // MBhT_9.17 //

Höre, o Herrscherin der Götter, den Stoff des Feueropfers, o Geliebte meines Lebens: entweder in einer aus Sand gefertigten [Grube] oder in einer Feuergrube (Kuṇḍa), o höchste Herrscherin. In einem Maß von zweiunddreißig Aṅgulas Breite, dem entsprechend [tief]; ein Maß von sechzehn Aṅgulas [tief] mache man die wohlgeformte Kuṇḍa, Geliebte. Darüber, o höchste Herrscherin, [in einem Maß von] ,Veda-Auge'-Fingern [Anm.: verschlüsselte Bhūtasaṃkhyā-Zahlenangabe, ,veda'=4, ,netra'=2 – genaue Anwendung auf das Maß unsicher], o Huldreiche; ebenso [nehme man] einen goldenen Topf, oder, wenn man dazu nicht in der Lage ist, einen kupfernen Topf. Einen dieser beiden Töpfe stelle man oben auf die Plattform (Vedikā), nachdem man ihn mit einem Paar Seidengewändern sorgfältig umwickelt hat. Man vollziehe das Feueropfer mit Bilva-Blättern wie vorgeschrieben, o Herrscherin der Götter, nach der Regel [der Beträufelung] mit den drei süßen Substanzen [Trimadhu]; dann wird gewiss Erfolg [erlangt]. Danach ist die Opfergabe (Dakṣiṇā) zu leisten, entsprechend dem zuvor genannten Vermögensumfang; man gebe als Lohn den doppelten Wert aller verwendeten Stoffe. Opfer ohne Dakṣiṇā gewähren weder Erfolg noch Befreiung; deshalb, o große Herrscherin, [gebe man] Dakṣiṇā nach [eigenem] Vermögen.

Vers 9.18-9.24

varāhavat samānīya janmamātre 'pi sundari / pāradaṃ tolakaṃ mānaṃ bhakṣayed bahuyatnataḥ // MBhT_9.18 // punas tolakamānaṃ hi mātṛdugdhaṃ tataḥ param / punaś ca bhakṣayed dhīmāṃs tato dugdhaṃ tu bhakṣayet // MBhT_9.19 // tataś ca vatsam ānīya navadvāraṃ prayatnataḥ / sūtrayogeṇa deveśi baddhaṃ kuryāt prayatnataḥ // MBhT_9.20 // tataś ca helakīmantram aṣṭottaraśataṃ japet / gajapramāṇaṃ deveśi dīrghaprasthaṃ tu khātakam // MBhT_9.21 // karīṣakeṇa deveśi pūrṇaṃ kuryād vicakṣaṇaḥ / tanmadhye sthāpayed vatsaṃ saṃdahed bahuyatnataḥ // MBhT_9.22 // vahnisthite maheśāni na spṛśet kuṇḍam uttamam / kuṇḍe suśītale jāta utthāpya bahuyatnataḥ // MBhT_9.23 // sarvaprakāśakaṃ mantram aṣṭottaraśataṃ japet / viśveśvaraṃ pravakṣyāmi śṛṇu pārvati sādaram // MBhT_9.24 //

Nachdem man [es] wie von einem Eber [herbeigeschafft] [Anm.: ,varāhavat', Sinn unsicher] herbeigeschafft hat, verzehre man, sogar im bloßen Zustand [seiner] Entstehung [Anm.: ,janmamātre', unsicher – evtl. ,frisch gewonnen'], Schöne, ein Tolaka-Maß Quecksilber mit großer Sorgfalt. Danach wiederum ein Tolaka-Maß Muttermilch; wiederum verzehre der Kluge [das Quecksilber], danach trinke er die Milch. Dann, nachdem man mit Sorgfalt ein neuntoriges Kalb [Anm.: ,navadvāraṃ vatsam', unsicher – möglicherweise ein rituelles Gefäß/Abbild mit neun Öffnungen, nicht notwendig ein wirkliches Tier] herbeigebracht hat, binde man es, o Herrscherin der Götter, sorgfältig mittels einer Faden-Technik. Dann rezitiere man den Helakī-Mantra hundertundacht Mal; [man grabe] eine elefantengroße, o Herrscherin der Götter, lang ausgedehnte Grube. Mit Kuhmist-Fladen fülle der Kundige [sie], o Herrscherin der Götter, ganz; in ihrer Mitte stelle man das Kalb auf [und] verbrenne es mit großer Sorgfalt gänzlich. Solange das Feuer brennt, o große Herrscherin, berühre man die vortreffliche Kuṇḍa nicht; ist sie in der Kuṇḍa gut abgekühlt, hebe man [die Substanz] mit großer Sorgfalt heraus. Man rezitiere den alles erhellenden Mantra hundertundacht Mal. Ich will nun das Viśveśvara[-Verfahren] verkünden – höre, Pārvatī, mit Ehrfurcht.

Alle drei mit [?] markiert, ohne die wörtliche Übersetzung zu glätten.

Vers 9.25-9.31

pāradaṃ tolakaṃ mānaṃ tāmrapātre tu lepayet / cūrṇaṃ kuryān maheśāni gandhakaṃ sārdhaṃ tolakam // MBhT_9.25 // samācchādya prayatnena cūrṇena parameśvari / saṃdahed bahuyatnena mandamandena vahninā // MBhT_9.26 // kṛṣṇavarṇaṃ reṇuyutaṃ dṛṣṭvā utthāpya sundari / rattipramāṇaṃ tad dravyaṃ bhakṣayed yadi sundari // MBhT_9.27 // satyaṃ satyaṃ sarvakuṣṭhaṃ bhakṣaṇān nāśam āpnuyāt / anupānam uṣṇatoyaṃ matsyādīn parivarjayet // MBhT_9.28 // evaṃ prayogaṃ deveśi na kuryāt putravān gṛhī / prathame divase putrān dvitīye divase dhanam // MBhT_9.29 // tṛtīye divase śaktiṃ caturthe divase gṛham / pañcame divase rogaṃ nāśaṃ tu jāyate dhruvam // MBhT_9.30 // ata eva maheśāni ātmasvastyayanaṃ caret / pūrvoktavidhinā mantrī caturguṇaṃ samācaret // MBhT_9.31 //

Ein Tolaka-Maß Quecksilber bestreiche man in einem Kupfergefäß; man mache Pulver, o große Herrscherin, von Schwefel [im Umfang] eineinhalb Tolaka. Nachdem man [es] sorgfältig mit dem Pulver bedeckt hat, o höchste Herrscherin, verbrenne man es mit großer Sorgfalt bei ganz gemächlichem Feuer. Hat man [es] schwarzfarben, mit Körnern versehen, gesehen [und] herausgehoben, Schöne, so verzehre man jene Substanz im Maß eines Ratti, wenn man will, Schöne. Wahrlich, wahrlich – durch [dieses] Verzehren erlangt jeder Hautaussatz (Kuṣṭha) [seine] Vernichtung; als Begleittrank [diene] warmes Wasser, Fisch u.ä. meide man. Diese Anwendung, o Herrscherin der Götter, soll ein Hausherr, der Söhne hat, nicht vollziehen: am ersten Tag [gehen] die Söhne [verloren], am zweiten Tag der Reichtum, am dritten Tag die [rituelle] Kraft, am vierten Tag das Haus, am fünften Tag die Krankheit [tritt ein] – die Vernichtung tritt gewiss ein. Deshalb, o große Herrscherin, vollziehe man ein Selbst-Segensritual; nach der zuvor genannten Vorschrift vollziehe der Mantra-Kundige [es] vierfach.
