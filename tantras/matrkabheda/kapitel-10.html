Mātṛkābhedatantra

Paṭala 10: Mātṛkābhedatantra, daśamaḥ paṭalaḥ Paṭala 10: Guru-Mantra-Einheit, Śabdabrahman-Meditation, Tieropfer-Vorschriften und Kali-Zeitalter-Theologie

Theologischer Auftakt zur Wesenseinheit von Guru, Mantra und Meditationsgottheit, gefolgt von der Śabdabrahman-Lehre (formlose Gottheit allein durch Klang erfahrbar). Zentraler Abschnitt: detaillierte Vorschriften zum Tieropfer (Balidāna) einschließlich Formel-Nomenklatur, Fleischverzehrverbot und Pflicht zum Genuss der Opferreste, sowie eine explizite Ersatz-Theologie, wonach das Balidāna im Kali-Zeitalter das nicht mehr durchführbare vedische Aśvamedha ersetzt. Schließt mit einer Phalaśruti, die das Tantra über Veden und Purāṇas stellt.

Vers 10.1-10.4

Mātṛkābhedatantra, daśamaḥ paṭalaḥ / śrīdevy uvāca / narākṛtiṃ guruṃ nātha mantraṃ varṇātmakaṃ tathā / dhyānānurūpiṇaṃ devam ekatvaṃ vā kathaṃ vada // MBhT_10.1 // śrīśiva uvāca / guruvaktrān mahāmantro labhyate sādhakottamaiḥ / yady eko jāyate vīryas tasya mūrtir bhaved dhruvam // MBhT_10.2 // devatāyāḥ śarīraṃ ca bījād utpadyate priye / guror ājñānusāreṇa cānyamūrtis tu jāyate // MBhT_10.3 // gurvādibhāvanād devi bhāvasiddhiḥ prajāyate / ata eva maheśāni caikatvaṃ parikathyate // MBhT_10.4 //

Mātṛkābhedatantra, zehnter Paṭala. Śrī Devī sprach: „Den menschengestaltigen Guru, o Herr, und ebenso den aus Lauten bestehenden Mantra, und den der Meditation entsprechenden Gott – wie [ist] deren Einheit [zu verstehen]? Sage es.“ Śrī Śiva sprach: „Aus dem Mund des Guru wird der große Mantra von den besten Übenden erlangt; wenn eine einzige Kraft (Vīrya) entsteht, wird deren Gestalt (Mūrti) gewiss. Und der Gottheit Leib entsteht aus dem Samen (Bīja), Geliebte; gemäß dem Befehl des Guru entsteht dann eine andere Gestalt. Durch die mit dem Guru beginnende Kontemplation (Bhāvanā), Devī, entsteht die Vollendung des [meditativen] Zustands (Bhāvasiddhi); eben deshalb, o große Herrscherin, wird [ihre] Einheit gelehrt.“

Zehnter Paṭala: eröffnet mit einer knappen theologischen Erörterung der Wesenseinheit von Guru, Mantra und Meditationsgottheit – ein Kernthema tantrischer Guru-Theologie, das bereits in Paṭala 7 (Śrīvidyā-Guru-Verehrung) anklang.

Vers 10.5-10.7

śrīdevy uvāca / yac cākṣuṣaṃ mahādeva tadākaraṃ vicintayet / acākṣuṣe mahādeva dhyānaṃ vā kīdṛśaṃ bhavet // MBhT_10.5 // śrīśiva uvāca / śabdabrahmamayaṃ devi mama vaktrād vinirgatam / ākārarahite devi yathā dhyānādikaṃ bhavet // MBhT_10.6 // tathaivoccāraṇenaiva bhaktiyuktena cetasā / satyaṃ satyaṃ maheśāni pratyakṣaṃ nātra saṃśayaḥ // MBhT_10.7 //

Śrī Devī sprach: „Was sichtbar (Cākṣuṣa) ist, großer Gott, dessen Gestalt mag man kontemplieren; [aber] bei dem, was unsichtbar (Acākṣuṣa) ist, großer Gott, wie wäre da die Meditation beschaffen?“ Śrī Śiva sprach: „Aus dem Wort-Brahman (Śabdabrahman) bestehend, Devī, aus meinem Mund hervorgegangen; bei dem, was ohne Gestalt (Ākārarahita) ist, Devī, so [geschieht] die Meditation u.a. Ebenso eben durch das bloße Aussprechen, mit einem von Hingabe erfüllten Geist; wahrlich, wahrlich, große Herrscherin, [wird es] unmittelbar wahrnehmbar (Pratyakṣa) – daran besteht kein Zweifel.“

Die Lehre, dass die formlose Gottheit allein durch klangliche Rezitation (Śabdabrahman-Doktrin) meditativ erfahrbar wird, korrespondiert mit der bereits in Paṭala 6 und 7 zentralen Bedeutung der Mantra-Rezitation als eigenständigem Erkenntnisweg.

Vers 10.8-10.10

śrīdevy uvāca / paśupradāne vākyaṃ tu kīdṛśaṃ vada śaṃkara / yena vākyena deveśa devī tuṣṭā bhavaty api // MBhT_10.8 // śrīśiva uvāca / mṛge mahiṣe coṣṭre ca paśuśabdaṃ na yojayet / chāgale ca tathā siṃhe vyāghre ca parameśvari // MBhT_10.9 // paśuśabdaṃ yojayitvā mahādevyai nivedayet / paśubhāvasthito mantrī mahiṣo dīyate yadi // MBhT_10.10 //

Śrī Devī sprach: „Aber wie sollte, o Śaṃkara, die Formel (Vākya) bei der Tier-Übergabe (Paśupradāna) beschaffen sein – durch welche Formel, o Herr der Götter, wird auch die Göttin zufrieden?“ Śrī Śiva sprach: „Bei Hirsch, Büffel und Kamel wende man das Wort ,Paśu' nicht an, ebenso bei Ziegenbock, Löwe und Tiger, o höchste Herrscherin. Nachdem man das Wort ,Paśu' angewandt hat, biete man [es] der großen Göttin dar; der im Paśu-Zustand [Anm.: ,paśubhāva' – vermutlich die erste, niedrigste der drei tantrischen Übungshaltungen paśu/vīra/divya, hier auf den ausführenden Mantra-Kundigen angewandt] befindliche Mantra-Kundige [handle so], wenn ein Büffel gegeben wird.“

chāgale ca tathā siṃhe vyāghre ca parama-īśvari
ebenso bei Ziegenbock, Löwe und Tiger, höchste Herrscherin
paśu-śabdam yojayitvā mahā-devyai nivedayet
nachdem man das Wort 'Paśu' angewandt hat, biete man es der großen Göttin dar
paśu-bhāva-sthitaḥ mantrī mahiṣaḥ dīyate yadi
der im Paśu-Zustand befindliche Mantra-Kundige, wenn ein Büffel gegeben wird

V.9-10 enthalten eine scheinbare Spannung: V.9 untersagt die Anwendung des Wortes ,paśu' u.a. auf den Büffel, V.10 spricht dann von der Anwendung des Wortes ,paśu' im Zusammenhang mit einer Büffelgabe – möglicherweise regelt der Text unterschiedliche Fälle oder unterscheidet nach der Übungsstufe des Praktizierenden (,paśubhāva', die niedrigste der drei klassischen tantrischen Sādhaka-Stufen paśu/vīra/divya – vgl. ,divyavīramate' in V.12); wörtlich wiedergegeben, ohne die Spannung aufzulösen.

Vers 10.11-10.15

balidānaṃ prakartavyaṃ na māṃsaṃ bhakṣayen naraḥ / samyak phalaṃ na labhate daśāṃśaṃ labhate priye // MBhT_10.11 // mahiṣādi pradātavyaṃ divyavīramate sthitaḥ / sa eva siddhim āpnoti phalaṃ samyak priyaṃvade // MBhT_10.12 // paśudānaṃ vinā devi pūjayen na kadācana / tathā ca nityapūjāyāṃ yadi śakto bhaven naraḥ // MBhT_10.13 // kevalaṃ balidānena siddho bhavati nānyathā / nirdhanaḥ parameśāni yadi pūjādikaṃ caret // MBhT_10.14 // vatsarānte pradātavyaṃ balim ekaṃ sureśvari / anyathā naiva siddhiḥ syād ājanma pūjanād api // MBhT_10.15 //

Die Tiergabe (Balidāna) ist zu vollziehen; das Fleisch soll der Mensch nicht verzehren – [sonst] erlangt er nicht die volle Frucht, [nur] ein Zehntel erlangt er, Geliebte. Büffel u.a. ist darzubringen von dem, der in der Haltung des göttlichen Helden (Divyavīra) [Anm.: vermutlich die höchste bzw. mittlere der drei Sādhaka-Stufen, s.o. zu V.10] steht; er allein erlangt die Vollendung, die volle Frucht, o Holdsprechende. Ohne die Tiergabe, Devī, verehre man niemals; und so [gilt] auch bei der täglichen Verehrung, wenn ein Mensch dazu imstande ist: allein durch die Tiergabe wird man vollendet, nicht anders. [Aber] ein Mittelloser, o höchste Herrscherin, wenn er die Verehrung u.a. vollzieht: am Jahresende ist eine einzige Tiergabe darzubringen, o Herrscherin der Götter; sonst würde die Vollendung selbst durch ein von Geburt an [fortgesetztes] Verehren nicht eintreten.

Der Verzehr des Opferfleischs wird untersagt (V.11), was im scheinbaren Spannungsverhältnis zur später (V.17-18) geforderten verpflichtenden Einnahme der ,Opferreste' (yajñāvaśeṣa) steht – vermutlich unterscheidet der Text zwischen dem rohen Fleisch des Opfertiers selbst (verboten) und den geweihten Speiseresten der gesamten Opferzeremonie (vorgeschrieben); nicht ausdrücklich im Text aufgelöst.

Vers 10.16-10.18

balidānaṃ mahāyajñaṃ kalikāle ca caṇḍike / aśvamedhādikaṃ yajñaṃ kalau nāsti sureśvari // MBhT_10.16 // kevalaṃ balidānena cāśvamedhaphalaṃ bhavet / yajñāvaśeṣaṃ yad dravyaṃ bhojanīyaṃ na cānyathā // MBhT_10.17 // yajñāvaśeṣabhogena sa yajñī nātra saṃśayaḥ / na bhakṣed yadi mohena na yajñaphalabhāg bhavet // MBhT_10.18 //

Die Tiergabe [ist] das große Opfer im Kali-Zeitalter, o Caṇḍikā; das Aśvamedha und die anderen [vedischen] Opfer gibt es im Kali[-Zeitalter] nicht, o Herrscherin der Götter. Allein durch die Tiergabe käme die Frucht des Aśvamedha zustande; welche Substanz vom Opfer übrig bleibt, ist zu verzehren, nicht anders [d.h. nur diese]. Durch den Genuss des Opferrests ist er wahrhaft der Opfernde – daran besteht kein Zweifel; verzehrt er [ihn] aus Verblendung nicht, wird er kein Teilhaber an der Opferfrucht.

Eine ausdrückliche Ersatz-Theologie: das blutige Tieropfer (Balidāna) ersetzt im gegenwärtigen Kali-Zeitalter das große vedische Pferdeopfer (Aśvamedha), da Letzteres als im Kali nicht mehr durchführbar gilt – ein verbreitetes Motiv spätvedisch-tantrischer Literatur zur Legitimierung neuer Ritualformen.

Vers 10.19-10.24

tyājyaṃ dravyaṃ kathaṃ devi mahādevyai nivedayet / brahmarūpaṃ mahātantraṃ mama vaktrād vinirgatam // MBhT_10.19 // sa pūtaḥ sarvapāpebhyo yadi caikākṣaraṃ śrutam / mahābhaktiyuto bhūtvā śṛṇoti paṭalaṃ yadi // MBhT_10.20 // kiṃ tasya dhyānapūjāyāṃ tīrthasnānena tasya kim / śabdabrahmamayaṃ jñātvā samastaṃ yadi caṇḍike // MBhT_10.21 // kevalaṃ śravaṇenaiva sa siddho nātra saṃśayaḥ / aṣṭādaśapurāṇānāṃ śravaṇenaiva yat phalam // MBhT_10.22 // caturvedena sāṅgena śravaṇenaiva yataḥ phalam / asya tantrasya deveśi kalāṃ nārhanti ṣoḍaśīm // MBhT_10.23 // brahmarūpam idaṃ tantraṃ sārāt sāraṃ parāt param // MBhT_10.24 //

„[Und] wie sollte die zu entsagende Substanz [Anm.: Bezug unklar, evtl. Fortsetzung der Devī-Frage nach der auszuschließenden Substanz] der großen Göttin dargebracht werden, Devī?“ [Śiva:] „Dieses große Tantra, von Brahmans Gestalt, ist aus meinem Mund hervorgegangen. Er wird rein von allen Sünden, selbst wenn nur eine einzige Silbe [davon] gehört wurde; wenn er, von großer Hingabe erfüllt, den [ganzen] Paṭala hört – was [bräuchte] der noch Meditation-Verehrung, was bräuchte er das Baden an Wallfahrtsorten (Tīrtha), wenn er, o Caṇḍikā, das Ganze als aus dem Wort-Brahman bestehend erkannt hat? Durch das bloße Hören allein wird er vollendet – daran besteht kein Zweifel; welche Frucht es vom Hören der achtzehn Purāṇas gibt, welche Frucht es vom Hören der vier Veden samt ihren Hilfswissenschaften (Aṅgas) gibt – [all das] verdient nicht einmal ein Sechzehntel dieses Tantra[s], o Herrscherin der Götter. Dieses Tantra, von Brahmans Gestalt, [ist] das Wesen des Wesens, das Höchste über dem Höchsten.“

Klassische Phalaśruti (Verkündigung des Hörlohns) am Kapitelende, die das eigene Tantra über die Veden samt Aṅgas und die achtzehn Purāṇas stellt – ein Standardtopos hinduistischer Textliteratur zur Selbstlegitimierung, hier mit der bereits aus Paṭala 6 bekannten Śabdabrahman-Theologie (Heiligkeit des bloßen Klangs) verbunden.
