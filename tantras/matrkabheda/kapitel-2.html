Mātṛkābhedatantra

Paṭala 2: Mātṛkābhedatantra, dvitīyaḥ paṭalaḥ Paṭala 2: Kuṇḍalinī-Physiologie – Zeugung, Geschlechtsbestimmung und Empfängnis

Nach dem alchemistischen Paṭala 1 wendet sich das Werk der Kuṇḍalinī-/Cakra-Physiologie zu: Maṇipūra/Nabellotos mit drei Kanälen (aufwärts zum Sahasrāra, mittig durch die Suṣumṇā, abwärts zur Yoni), die Empfängnis durch Vereinigung von Same und weiblichem Blut im Nabellotos, eine Geschlechtsbestimmungslehre nach dem Samen-Blut-Verhältnis, die Schwangerschaft als Wachsen einer inneren ,Blüte' bis zur Geburt, und eine abschließende Einladung zum rituellen Liebesspiel als Quelle kosmischer Fruchtbarkeit.

Vers 2.1-2.3

Mātṛkābhedatantra, dvitīyaḥ paṭalaḥ / śrīdevy uvāca / vada īśāna sarvajña sarvatattvavidāṃ vara / yat tvayā kathitaṃ nātha mama saṅge vihārataḥ // MBhT_2.1 // kathaṃ vā jāyate putraḥ śukrasya katra saṃsthitiḥ / vardhamānaṃ sadā liṅgaṃ praveśo vā kathaṃ bhavet // MBhT_2.2 // bhītiyuktā hy ahaṃ nātha trāhi māṃ duḥkhasaṅkaṭāt // MBhT_2.3 //

Mātṛkābhedatantra, zweiter Paṭala. Śrī Devī sprach: „Sprich, o Herr, Allwissender, Bester der Kenner aller Wahrheiten! [Erkläre], was du mir während unseres Beisammenseins beim Liebesspiel [bereits angedeutet, aber nicht ausgeführt] hast: Wie wird ein Sohn geboren, wo befindet sich der Same? Wie geschieht das ständige Anschwellen des Liṅga, oder wie erfolgt das Eindringen? Denn ich bin von Furcht erfüllt, o Herr – rette mich aus der Bedrängnis des Leids.“

Übergang zum zweiten Paṭala: von der Alchemie (P1) zur Kuṇḍalinī-/Zeugungsphysiologie. Devīs Frage bezieht sich auf ein zuvor (außerhalb des Textes bzw. beim Liebesspiel selbst) Angedeutetes – ein für Tantras typischer Rahmen, in dem der eigentliche Lehrinhalt als Fortsetzung eines intimen Zwiegesprächs präsentiert wird.

Vers 2.4-2.7

śrīśaṅkara uvāca / maṇipūraṃ mahāpadmaṃ suṣumṇāmadhyasaṃsthitam / tasya nālena deveśi nābhipadmaṃ manoharam // MBhT_2.4 // vakratrayasamāyuktaṃ sadā śukravibhūṣitam / ūrdhvaṃ nālaṃ sahasrāre ataḥ śukravibhūṣitam // MBhT_2.5 // tasmād eva stanadvandvaṃ vardhamānaṃ dine dine // MBhT_2.6 // madhyanālaṃ suṣumṇāntaṃ vṛntākāraṃ suśītalam / āyonyagram adhonālaṃ sadānandamayi śive // MBhT_2.7 //

Śrī Śaṅkara sprach: „Das Maṇipūra, der große Lotos, befindet sich inmitten der Suṣumṇā; durch seinen Stängel [ist es verbunden], o Göttin-Herrscherin, mit dem bezaubernden Nabellotos. [Dieser ist] mit einer dreifachen Biegung versehen, stets mit Same geschmückt [?]; der aufwärtsführende Kanal [reicht] zum Sahasrāra, von dort ebenfalls mit Same geschmückt [?, Anm.: Wiederholung im Sanskrit unklar]. Von eben diesem [Kanal] aus wächst das Brustpaar Tag für Tag. Der mittlere Kanal, der in der Suṣumṇā endet, ist stängelförmig, sehr kühl; der untere Kanal, dessen Spitze bis zur Yoni reicht [?], [gehört dir], o stets wonnevolle, huldreiche [Göttin].“

Beschreibung dreier Kanäle (nāla), die vom Maṇipūra-/Nabellotos ausgehen: ein aufwärtiger zum Sahasrāra (Scheitel), ein mittlerer innerhalb der Suṣumṇā, ein unterer zur Yoni. Die genaue anatomisch-yogische Zuordnung bleibt, wie in tantrischer Kuṇḍalinī-Literatur häufig, bildhaft-metaphorisch und nicht im modernen physiologischen Sinn zu verstehen. Die zweimalige Wendung „sadā śukravibhūṣitam“ (V.5) ist im Sanskrit auffällig wiederholt [?] – möglicherweise Textverderbnis oder bewusste Wiederholung zur Betonung.

Vers 2.8-2.12

śṛṇu cārvaṅgi subhage tanmadhye liṅgatāḍanāt / yad rūpaṃ paramānandaṃ tan nāsti bhuvanatraye // MBhT_2.8 // nābhipadmaṃ tu yad rūpaṃ tac chṛṇuṣva samāhitaḥ / bindusthānaṃ madhyadeśe sadā padmavirājitam // MBhT_2.9 // bāhyadeśe cāṣṭapatraṃ caturasraṃ tu tadbahiḥ / caturdvārasamāyuktaṃ suvarṇābhaṃ savṛttakam // MBhT_2.10 // tatpatreṇa bhavet puṣpaṃ vṛntayuktaṃ tripattrakam / praphulle tu tripatrāre bāhye rudhiradarśanam // MBhT_2.11 // etanmadhye maheśāni yadi syāl liṅgatāḍanam / padmamadhye gate śukre saṃtatis tena jāyate // MBhT_2.12 //

„Höre, o Schönglied­rige, Glückliche: Was für eine Gestalt höchster Wonne durch das Stoßen des Liṅga inmitten dessen [entsteht] – das gibt es sonst nicht in den drei Welten. Was aber die Gestalt des Nabellotos betrifft, so höre das mit gesammeltem Geist: In der Mittelregion [befindet sich] die Bindu-Stätte, stets lotosgleich erstrahlend. Im äußeren Bereich [sind] acht Blütenblätter, außerhalb davon aber ein Viereck, versehen mit vier Toren, goldfarben und rund. Aus jenem Blatt entsteht eine Blüte, stängelversehen, dreiblättrig; ist aber das Dreiblatt voll erblüht, zeigt sich außen ein Blutschein [Anm.: möglicherweise Anspielung auf die Menstruation]. Wenn inmitten dessen, o große Herrscherin, ein Stoßen des Liṅga stattfindet [und] der Same in die Mitte des Lotos gelangt, entsteht dadurch Nachkommenschaft.“

Detaillierte bildhafte Beschreibung des Nabellotos (aṣṭapatra, mit vierseitigem/vier-torigem äußeren Umriss – ein klassisches Yantra-/Cakra-Schema) und der darin entstehenden dreiblättrigen Blüte als Ort der Empfängnis. „Rudhiradarśanam“ (,Anblick von Blut') ist hier tentativ als Hinweis auf die Menstruation gedeutet, könnte aber auch rein bildhaft-farblich gemeint sein [?].

Vers 2.13-2.16

puruṣasya tu yac chukraṃ śakteraktādhiko bhavet / tadā kanyā bhaved devi viparītaḥ pumān bhavet // MBhT_2.13 // ubhayos tulyaśukreṇa klībaṃ bhavati niścitam // MBhT_2.14 // śṛṇu cārvaṅgi subhage puṣpamāhātmyam uttamam / madhye tacchukrasaṃyoge vardhate tad dine dine / evaṃ diṅmāsasamprāpte tatpuṣpaṃ vṛntasaṃyutam // MBhT_2.15 // galite parameśāni vyakto bhavati saṃtatiḥ // MBhT_2.16 //

„Ist aber der Same des Mannes geringer als das Blut der Śakti [der Frau], so entsteht, o Göttin, ein Mädchen; im umgekehrten [Fall] entsteht ein Knabe. Bei gleichem Samen beider entsteht mit Sicherheit ein Klība [ein Geschlechtsloser]. Höre, o Schönglied­rige, Glückliche, von der höchsten Erhabenheit der Blüte: In ihrer Mitte wächst sie, bei Vereinigung mit jenem Samen, Tag für Tag; wenn so der [zehnte(?)] Monat erreicht ist, [löst sich] jene Blüte samt ihrem Stängel. Ist sie abgefallen, o höchste Herrscherin, wird die Nachkommenschaft offenbar [geboren].“

Geschlechtsbestimmungslehre nach dem relativen Verhältnis von männlichem Samen (śukra) und weiblichem „Blut“ (rakta, hier als Śaktis Anteil bezeichnet) – ein in āyurvedischer wie tantrischer Literatur verbreitetes Motiv. Der Ausdruck „diṅmāsa“ (V.15) ist nicht sicher zu deuten [?]; denkbar wäre eine Verschreibung für „daśamāsa“ (,zehnter Monat', d.h. der übliche Geburtstermin), was inhaltlich gut passen würde, hier aber nicht stillschweigend korrigiert, sondern offen als Unsicherheit markiert wird.

Vers 2.17-2.19

śrīdevy uvāca / kiṃcid rogādisambhūte kṛmikīṭādisambhave / tasmajjīvaṃ praṇaśyanti sā nārī jīvyate katham // MBhT_2.17 // śrīśaṅkara uvāca / asya puṣpasya māhātmyaṃ kiṃ vaktuṃ śakyate mayā / bindusthānaṃ sahasraṃ tu puṣpamadhye priyaṃvade // MBhT_2.18 // budbudā yatra tiṣṭhanti tatraiva saṃtatir bhavet / evaṃ krameṇa deveśi sahasraṃ saṃtatir yadi / vardhamānaṃ mahāpuṣpaṃ pīḍā kiṃcin na jāyate // MBhT_2.19 //

Śrī Devī sprach: „Wenn irgendeine Krankheit o.ä. entsteht, [wenn] Würmer, Insekten u.ä. entstehen, [und] dadurch die Lebenskeime [?] zugrunde gehen – wie überlebt jene Frau dann?“ Śrī Śaṅkara sprach: „Wie könnte ich die Erhabenheit dieser Blüte überhaupt in Worte fassen? Tausend Bindu-Stätten [gibt es] inmitten der Blüte, o Süßredende. Wo Blasen verweilen, dort eben entsteht Nachkommenschaft. Wenn so der Reihe nach, o Göttin-Herrscherin, tausendfach Nachkommenschaft [entstünde, während] die große Blüte wächst, entstünde dennoch keinerlei Schmerz.“

Die Frage nach Fehlgeburt/Krankheitsgefahr (V.17, „tasmajjīvaṃ“ vermutlich für „tasmāj jīvaṃ“, Sandhi-Fuge unklar [?]) wird von Śaṅkara nicht direkt beantwortet, sondern mit einer erneuten Lobpreisung der unerschöpflichen Fruchtbarkeit der ‚Blüte' (tausend Bindu-Stätten, jede ein potentieller Ursprung neuer Nachkommenschaft) pariert – eine für den Dialogstil des Werks typische, eher enkomiastische als sachlich-erklärende Antwort.

Vers 2.20-2.22

mayā sārdhaṃ maheśāni vihāraṃ kuru yatnataḥ / vihāre yo bhavet putro gaṇeśaḥ sa ca kīrtitaḥ // MBhT_2.20 // apare parameśāni tava putraprasādataḥ / pṛthivyāṃ jāyate sṛṣṭir nirvighnena yathocitam // MBhT_2.21 // etac chrutvā tato devi madanānalavihvalā / śivenāliṅgitā devī śivākāreṇa vai tadā // MBhT_2.22 //

„Vollziehe mit mir, o große Herrscherin, eifrig das Liebesspiel. Der Sohn, der im Liebesspiel entsteht, wird als Gaṇeśa [Anm.: hier wohl ,Herr einer Schar/eines Gaṇa', nicht zwingend der Gott Gaṇeśa] gepriesen. Ferner, o höchste Herrscherin, entsteht durch die Gnade deines Sohnes auf Erden die Schöpfung ungehindert, wie es sich gebührt.“ Nachdem sie dies gehört hatte, o Göttin [Erzählerin-Anrede], wurde die Göttin, überwältigt vom Feuer des Liebesverlangens, sogleich von Śiva in dessen [Śiva-]Gestalt umarmt.

Abschluss des zweiten Paṭala mit einer Einladung zum rituellen Liebesspiel (vihāra) als Ursprung sowohl göttlicher Nachkommenschaft (,Gaṇeśa' als Sohn) als auch kosmischer Fruchtbarkeit auf Erden – ein für Kaula-/Śākta-Traditionen charakteristisches Verschränken von sexuellem Ritual und kosmogonischer Wirkung. Die Schlusszeile mit der Rahmen-Anrede „devi“ und der erneuten Umarmungsszene deutet auf die im ersten Paṭala etablierte Dialog-im-Liebesspiel-Fiktion zurück.
