Paṭala 5: Mātṛkābhedatantra, pañcamaḥ paṭalaḥ Paṭala 5: Bhasma-Alchemie, ein sechsfacher Sekret-Katalog und die Wirkkraft des vollendeten Präparats

Mātṛkābhedatantra

Ausführliches alchemistisches Kapitel: Herstellung von Bhasma (kalzinierter Asche) aus Quecksilber, eingebettet in ein Vorbereitungsritual mit sechzehn Ton-Liṅgas und vollem Pūjā-Zeremoniell (V.1-15); die eigentliche Bhasma-Prozedur in zwei Varianten, davon eine unter Verwendung ritueller weiblicher Sekrete ('Blüten', puṣpa) als Bindemittel (V.16-26); ein Exkurs, der sechs solcher 'Blüten'-Typen nach Herkunftsumständen definiert (V.27-33) – klassisches Kaula-Material, philologisch unverkürzt wiedergegeben; abschließend Goldprobe, medizinische Wirkung und eine hymnische Beschreibung der übermenschlichen Fähigkeiten des vollendeten Adepten (V.34-43).

Mātṛkābhedatantra, pañcamaḥ paṭalaḥ / śrīcaṇḍikovāca / pāradaṃ bhasmanirmāṇaṃ kenopāyena śaṃkara / tad ahaṃ śrotum icchāmi yadi te 'sti kṛpā mayi // MBhT_5.1 // śrīśaṃkara uvāca / pārade bhasmanirmāṇe nānāvighnāni pārvati / ata eva hi tatrādau śāntiṃ kuryād dvijottamaḥ // MBhT_5.2 // varayet karmakartāraṃ vakṣyamāṇavidhānataḥ / pūjayet ṣoḍaśaliṅgaṃ pārthivaṃ parvatātmaje // MBhT_5.3 // ṣoḍaśenopacāreṇa toḍaloktavidhānataḥ / bhogayogyaṃ pradātavyaṃ madhuparkaṃ sureśvari // MBhT_5.4 //

Mātṛkābhedatantra, fünfter Paṭala. Śrī Caṇḍikā sprach: „Durch welches Mittel, Śaṅkara, wird aus Quecksilber Bhasma [kalzinierte Asche] hergestellt? Das möchte ich hören, wenn du Mitleid mit mir hast.“ Śrī Śaṅkara sprach: „Bei der Herstellung von Bhasma aus Quecksilber gibt es mancherlei Hindernisse, o Pārvatī; deshalb soll zu deren Beginn der beste der Zweifachgeborenen ein Friedensritual [Śānti] vollziehen. Man wähle den Ausführenden gemäß der sogleich zu verkündenden Vorschrift; man verehre sechzehn Liṅgas aus Ton, o Tochter des Berges, mit dem sechzehnfachen Opferdienst, gemäß der im Toḍala[-Tantra?] gelehrten Vorschrift [Anm.: Referenz unsicher identifizierbar]; genussgerechte [Gaben] sind darzureichen, [darunter] Madhuparka, o Götterherrscherin.“

Vers 5.16-5.21

Śrī Caṇḍikā sprach: „Die Vorgehensweise, o höchster Götterherr, beim Bhasma-Herstellungsritus, durch welche, einmal ausgeführt, [der Stoff] zu Bhasma wird, o Mächtiger [erkläre das].“ Śrī Śaṅkara sprach: „Nachdem man Quecksilber beschafft hat, o Göttin, lege man es auf eine Steinplatte; darüber rezitiere man den aus neun, von allen verehrten [Silben] bestehenden Mantra. Tausendundacht Mal rezitiere, o Göttin-Herrscherin, der vorderste der Übenden, auf einem morgenrot-farbenen Tuch, versehen mit der ,Svayambhū-Blüte' [Anm.: siehe die Definition der Blütenarten weiter unten]. Nachdem man das Quecksilber, o Göttin, in ein Paar Tongefäße gelegt hat, o Huldreiche, binde man es mit einem mit der ,Blüte' versehenen Faden, mit großer Sorgfalt. Mit dem [aus] Getreide [gewonnenen] Sud [?], o höchste Herrscherin, bestreiche man mit großer Sorgfalt [das Gefäß] und lasse es in der Sonnenglut trocknen. Und wiederum bestreiche der Kundige [es], dann lege man es ins Feuer; an der achten oder neunten Nacht [des Mondmonats] werfe man es jedoch niemals [hinein], o Götterherrscherin.“

Definition unten V.27ff.) wird hier als rituelle Substanz zur Imprägnierung des Bindetuchs verwendet – ein für Kaula-Alchemie charakteristisches Element, das körperliche Sekrete als machtvolle Ritualstoffe behandelt. ,Muktidhārājala' (V.20) bleibt als genauer Fachbegriff für einen Getreide-Sud unsicher [?].

śrīcaṇḍikovāca / svayambhu kīdṛśaṃ nātha kuṇḍagolaṃ tu kīdṛśam / svapuṣpaṃ kīdṛśaṃ nātha vajrapuṣpaṃ tu kīdṛśam / sarvakālodbhavaṃ nātha kīdṛśaṃ vada śaṃkara // MBhT_5.27 // śrīśaṃkara uvāca / vivāharahitā kanyā prathamaṃ puṣpasaṃyutā / tacchoṇitaṃ maheśāni svayambhu nātra saṃśayaḥ // MBhT_5.28 // bhartari vidyamāne tu yā kanyā cānyajā śive / tadudbhavaṃ kuṇḍapuṣpaṃ sarvakāryārthasādhakam // MBhT_5.29 // mṛte bhartari deveśi yā kanyā anyajā śive / tadudbhavaṃ golapuṣpaṃ devavaśyakaraṃ param // MBhT_5.30 // vivāhitāyāḥ kanyāyāḥ prathame ṛtusambhave / tacchoṇitaṃ maheśāni svapuṣpaṃ sarvamohanam // MBhT_5.31 // vivāhitāyāḥ kanyāyāḥ puruṣasya ca tāḍanāt / yadi puṣpaṃ samudbhūtaṃ vajraṃ tat parikīrtitam // MBhT_5.32 // vivāhitāyāḥ kanyāyāḥ pratimāse ca yad bhavet / sarvakālodbhavaṃ puṣpaṃ kathitaṃ vīravandite // MBhT_5.33 //

Śrī Caṇḍikā sprach: „Was ist Svayambhu, o Herr, und was Kuṇḍa[-puṣpa] und Gola[-puṣpa]? Was ist Svapuṣpa, o Herr, und was Vajrapuṣpa? Was ist ,zu jeder Zeit Entstehendes' [Sarvakālodbhava], o Herr – sage es, Śaṅkara.“ Śrī Śaṅkara sprach: „Bei einem unverheirateten Mädchen, wenn es mit der ersten ,Blüte' [Menstruation] versehen ist – jenes Blut, o große Herrscherin, ist Svayambhu, ohne Zweifel. Wenn aber, während der Ehemann lebt, ein Mädchen von einem anderen [gezeugt] geboren wird, o Huldreiche – die daraus entstehende ,Blüte' [ist] Kuṇḍapuṣpa, alle Zwecke erfüllend. Wenn aber der Ehemann tot ist, o Göttin-Herrscherin, [und] ein Mädchen von einem anderen [gezeugt wird] – die daraus entstehende ,Blüte' [ist] Golapuṣpa, das höchst wirksam macht, selbst Götter gefügig. Bei der ersten Menstruation einer verheirateten Frau – jenes Blut, o große Herrscherin, [ist] Svapuṣpa, alles bezaubernd. Wenn bei einer verheirateten Frau durch den Beischlaf des Mannes eine ,Blüte' entsteht, wird jene ,Vajra[-Blüte]' genannt. Eine für Kaula-/vāmācāra-Tantras charakteristische Klassifikation weiblicher menstrualer/sexueller Sekrete (,Blüten', puṣpa) nach Herkunftsumständen (unverheiratet/verheiratet, Ehemann lebend/tot, aus Beischlaf, regelmäßig) als rituell einzusetzende Substanzen – hier als Zutat für das Bhasma-Ritual (V.18: 'Svayambhū-Blüte'). Solche Sekret-Taxonomien sind historisch in mehreren Śākta-Tantras belegt und werden hier philologisch wörtlich, ohne Beschönigung oder Auslassung, wiedergegeben.

„Selbst wenn man täglich, o höchste Herrscherin, mit hundert Frauen Umgang pflegte, würde man nicht an Kraft u.a. verlieren – [dieser Stoff] ist höchst wirksam für die Mehrung der Leuchtkraft [Tejas]. Wenn man dabei der Meditation hingegeben ist, sehe ich [Śiva] überhaupt keinen Tod [mehr für ihn]; allein beim Anblick seines Reichtums wird sogar Kubera beschämt.
