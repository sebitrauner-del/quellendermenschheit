Paṭala 20: pātālanarakavarṇanam Teil 2, Adhyāya 5: Die Bewohner Rasātalas und Pātālas, Śeṣas Gestalt, Yamas Hof, und der Katalog der 108 Höllen

Prakāśa-Saṃhitā

PS_2,5.1-44. Von "Śrī Bhagavān" gesprochenes Kapitel zur Unterwelt-Kosmographie: die von Hari/Rāma/Kṛṣṇa besiegten Dämonenscharen in Rasātala (bewacht von der Höllenhündin Saramā); der tausendköpfige Śeṣa in Pātāla mit ausführlicher Ikonographie, meditierend über Nārāyaṇa; Yamas Hof in der Stadt Saṃyamanī mit den Schreibern Citra/Citragupta und dem Gerichtsverfahren über Verdienst und Sünde; ein bemerkenswerter Abschnitt, in dem Krankheiten (Wind-/Gallen-/Schleimstörungen, Herzleiden usw.) als personifizierte Höllenwesen auftreten; ein vollständiger Katalog der 108 Höllen (v.a. Namenskatalog, viele Einzelnamen unsicher überliefert); und ein kosmologischer Schluss über zwei ewige vs. viele zeitlich begrenzte Höllen sowie den zyklischen Wechsel der unteren Götter zwischen grobstofflicher Existenz und Maharloka-Aufenthalt.

Vers 1-9

śrībhagavānuvāca. rasātaledhasthāddānavāḥ śatakoṭiśaḥ / daityāśca yātudhānāśca paulomāḥ kālakeyakāḥ // 1 // nivātākavacādhīrāḥ rākṣasāśca surāṇakāḥ / piśācā antyajāsṛkyāḥ mahākumati(mudi)no jarāḥ // 2 // vasanti cakrabhayato hareḥ sarvabhayādapi / ye kecittātvikāstatra saṃvasanti surarṣabhāḥ // 3 // pratimanvantareṣvete varṣesmin bhāratekhilāḥ / harīrasurasadvipragoyoṣidaparāśramān // 4 // dūṣayitvā pātayitvā kecit pūrṇānyathādhiyaḥ / nitye vasanti narake hatā haryādi daiḥdvagddha // 5 // nityaduḥsādhanābhūyo rasātalamupāśritāḥ / bhūmau bhūtvā brahmarudravarairloko(kā)pakāriṇaḥ // 6 // sarvāvatārai rāmeṇa kṛṣṇenāpi hatāḥ khilāḥ / vasanti nityanarake kālādyāsyanti vai tamaḥ // 7 // tasmin hi saramānāmnī śunī brahmavarodbhavā / sadārtān bhīṣayanti daityān yamasya vaśavartinī // 8 // kṣīṇāyuṣastatradaityāḥ svapne dṛṣṭvā sudarśanam / mṛtāyāsyanti narakaṃ tadvaṃśyā(syā)nāṃ sa āśrayaḥ(maḥ) // 9 //

Der Erhabene [Bhagavān] sprach: In Rasātala, [zuunterst] gelegen, wohnen Dānavas zu hundert Millionen, und Daityas, und Yātudhānas, die Paulomas, die Kālakeyas, die standhaften Nivātakavacas, und Rākṣasas und Surāṇakas [?], Piśācas, die niedriggeborenen Blutsauger [?], die überaus törichten, altersschwachen [Dämonen] – sie wohnen [dort] aus Furcht vor Haris Diskus und tatsächlich aus Furcht vor allem; welche „Wesenskundigen” (tāttvika) unter ihnen, die vortrefflichen [Wesen], gibt, wohnen ebenfalls dort zusammen [mit ihnen]. Diese, in jedem Manvantara, in diesem Bhārata[-Land] gänzlich [wirkend], schänden Hari-Verehrer, gute Brahmanen, Kühe, Frauen und die Einsiedeleien anderer, und bringen [sie] zu Fall; manche, [deren] Sinn ganz [vom Bösen] erfüllt ist, wohnen in der ewigen Hölle, [zuvor] von Hari u.a. erschlagen [?, Versende korrupt]. Zu immerwährendem Widerstand geworden, in Rasātala Zuflucht genommen habend, [einst] auf der Erde weilend, waren sie, trotz der Gunstbezeigungen Brahmās und Rudras, Schädiger der Welt. Von allen Avatāras, von Rāma, auch von Kṛṣṇa erschlagen, wohnen sie alle gänzlich in der ewigen Hölle; mit der Zeit werden sie fürwahr in die Finsternis eingehen. Denn dort [erschreckt] eine Hündin namens Saramā, entstanden aus einem Segen Brahmās, dem Willen Yamas untertan, ständig die gequälten Daityas. Die dortigen Daityas, [deren] Lebenszeit erschöpft ist, gehen, nachdem sie im Traum den Sudarśana[-Diskus] erblickt haben, nach dem Tod in die Hölle ein; jene [Hündin/jener Diskus] ist die Zuflucht [bzw. der Untergang] für ihre Sippe [?].

Vers 10-16

tadadhastāttu pātāle uttare diśi bhāsure / sahasravadanaḥ śeṣaḥ sarvaistātvikapannagaiḥ // 10 // samasta nāgakanyābhiḥ pūjito ratnamaṇḍape / dhyāyannārāyaṇaṃ devaṃ sadāvasati sāmaraḥ // 11 // sahasrabhānubhādīpyatkirīṭāvalimaṇḍitaḥ / sampūrṇaśāradaśaśichavikoṭyadhikadyutiḥ // 12 // nityāmṛtasravacchubhraphaṇāmaṇḍalamaṇḍitaḥ / sadaikakuṇḍalo bhāsvan musalaḥ sahalaḥ prabhuḥ // 13 // bhānuprabhāmuṇmūrdhanyamaṇiśrīhṛtasarvaruk / hāranūpuravalayakaṅkaṇāṅgulikādibhiḥ // 14 // anekamaṇisadbhāsva(tkaṭi)tkirīṭasūtrādikaḥ prabhuḥ / surāsurakirīṭastharatnāchāditapādukaḥ // 15 // gandhamālyādisurabhidhyāyannāste virāṭsvayam / pātāladakṣiṇe bhāge saṃya(mya)minyāṃ puraḥ prabhuḥ // 16 //

Und unterhalb davon, in Pātāla, in der strahlenden nördlichen Richtung, [weilt] der tausendköpfige Śeṣa, von allen wesenskundigen Schlangen und von sämtlichen Nāga-Mädchen in einem Juwelenpavillon verehrt; über den Gott Nārāyaṇa meditierend, weilt er, zusammen mit den Unsterblichen, dort beständig. [Er ist] geschmückt mit einer Reihe von Kronen, die mit dem Glanz tausend Sonnen erstrahlen, [sein] Glanz übertrifft zehn Millionen Male den des vollen Herbstmondes. Geschmückt mit einem Kranz weißer, stets von Nektar triefender Hauben, stets ein einzelnes [Ohrgehänge-]Paar tragend, strahlend, der Herr, [bewaffnet] mit Keule und Pflug. Auf dessen Haupt der Glanz eines sonnenhell strahlenden Juwels alle Krankheit hinwegnimmt; [geschmückt] mit Halsketten, Fußreifen, Armringen, Armbändern, Fingerringen u.a. Der Herr, [geschmückt] mit vielen Juwelen, strahlendem [Hüft-]Gürtel, Kronenband u.a., dessen Sandalen mit den in den Kronen von Göttern und Dämonen [eingefassten] Juwelen bedeckt sind [d.h. vor dem sich Götter und Dämonen mit gekrönten Häuptern niederwerfen]. Duftend von Sandelpaste, Blumengirlanden u.a. Wohlgerüchen, meditierend, weilt der Virāṭ selbst [dort]. Im südlichen Teil von Pātāla, in der Stadt Saṃyamanī, [befindet sich] der Herr [Yama] –

Vers 17-24

śyāmalāvallabho daṇḍadharo mahiṣavāhanaḥ / samavartī yamaḥ pretapatiḥ nīlāñjanādriruk // 17 // sarvābharaṇasampannaḥ dharmarāṭ rāmacintakaḥ / bhānuputroścātracitracitraguptau sulekhakau // 18 // yasyājñāyā bhāratotthapuṇyapāpacayasya tu / tatra dharmaḥ pravaktāraḥ tattanmanvantarasthitāḥ // 19 // ṛṣayaḥ sarvadevopadevāstatparicārakāḥ / ūrdhvakeśā virūpākṣāḥ nīlavarṇabhayaṅkarāḥ // 20 // tadājñākāriṇāstasya kiṅkarāḥ pāśapāṇayaḥ / niṣṭhurāḥ nirghṛṇāḥ krūrāḥ mahāparighapāṇayaḥ // 21 // bhāratāt pāpino badhvāhyānīyante yamāntikam / daśalakṣamatāste tu ghorāstāḍanabharjanaiḥ // 22 // ghorādhvāne kṛṣantyete nitarāṃ kṛtapāpinaḥ / sa tānabhyagatān dṛṣṭvā yamadaṇḍaṃ paretarāṭ // 23 // teṣāṃ mūrdhni sthāpayati yātanā dehināṃ tadā / puṇyapāpāni te sarve kīrtayanti kṛtāni ca // 24 //

Der Geliebte der Śyāmalā, der Stabträger, dessen Reittier der Büffel ist, der Unparteiische, Yama, Herr der Verstorbenen, an Glanz einem Berg aus dunklem Augenschminke-Gestein gleich, ausgestattet mit allem Schmuck, der Dharma-König, der auf Rāma Sinnende, der Sohn Bhānus [der Sonne] – und dort [bei ihm sind] Citra und Citragupta, die beiden kundigen Schreiber. Auf dessen Befehl hin [wird] die Summe von Verdienst und Sünde, [die] in Bhārata entstanden [ist, verzeichnet]; dort sind Dharma [und andere] die Verkünder [des Urteils], je nach ihrem Manvantara eingesetzt – Ṛṣis, alle Götter und Untergötter sind seine Diener; [und ferner Wesen mit] emporstehendem Haar, entstellten Augen, dunkler Hautfarbe, furchterregend, seine Befehlsausführenden, Diener mit Fangstricken in der Hand, hart, mitleidlos, grausam, mit großen Eisenkeulen in der Hand. Sie binden die Sünder aus Bhārata und bringen sie zu Yama; sie sind zu einer Million [gezählt], schrecklich, mit Schlägen und Sengungen. Auf schrecklichem Weg schleifen sie diese, die überaus viel Sünde begangen haben; er, der König der Verstorbenen, hat, nachdem er die Herangebrachten erblickt hat, den Yama-Stab; auf deren Haupt legt er [ihn]; dann [beginnt] die Qual der verkörperten Wesen. Sie alle verkünden [dann] die von ihnen begangenen Verdienste und Sünden.

Vers 25-31

tatra tatvātmikāḥsarve satyamityavadan sthitāḥ / patreṣu tāni(ḷḥi) likhitānyapi te prapaṭhanti ca // 25 // sukhaduḥkhātmakaphalaṃ vadanti ṛṣisattamāḥ / daśalakṣamitāsteṣāṃ yamadūtāstu nārake // 26 // pātayitvā tāḍayanti yathā pāpānusārataḥ / viṃśallakṣamitāstatra(sya) sadā rogābhimāninaḥ // 27 // te vātapittaśleṣmādyāḥ sannipātajvarādayaḥ / bhagandarātisārāśca vamanārucidurvraṇāḥ // 28 // hemapīnasabādharyaddhṛ(hṛ)drogādyāstadantike / vasanti pāpaphaladāḥ kvaciddehakṣayaṅkarāḥ // 29 // śvāhivṛścikadaṃśāṃśī viṣadurvṛkarūpakāḥ / viṃśallakṣāstu narake patitānāṃ prabādhakāḥ // 30 // pātāle saṃvasantyete narakā bahurūpakāḥ / durgatirnirayaścaiva mahārauravarauravau // 31 //

Dort erklären alle die wesenskundigen [Wächter], stehend: „Es ist wahr”; sie lesen auch das auf den [Aufzeichnungs-]Blättern Geschriebene laut vor. Die vortrefflichsten Ṛṣis verkünden die aus Lust und Leid bestehende Frucht [der Taten]; eine Million von ihnen sind Yamas Boten in der Hölle, welche, nachdem sie [die Sünder] niedergeworfen haben, sie entsprechend ihrer Sünde schlagen; zwei Millionen dort [sind] die, welche stets Krankheiten verkörpern [d.h. personifizierte Leiden] – sie [erscheinen als] Wind-, Gallen-, Schleim[-Störungen] u.a., zusammengesetzte Fieber u.a., Fisteln, Ruhr, Erbrechen, Appetitlosigkeit, schlecht heilende Wunden, goldfarbener [?] Schnupfen, Herzleiden u.a. – dort in der Nähe wohnen sie, Austeiler der Sündenfrucht, mancherorts Verursacher des Körperverfalls. In Gestalt von Hunde-, Schlangen- und Skorpionbissen, in Gestalt giftiger, bösartiger Wölfe – zwei Millionen [solcher Wesen] sind es, die in der Hölle die Gefallenen quälen. In Pātāla wohnen diese vielgestaltigen Höllen: Durgati und Niraya, und Mahāraurava und Raurava,

– [ferner] Saṅghāta, [die] mit Namen Kālasūtra, [die] mit Namen Avarcas [?], Anirodhana [?], Tailayantra [Ölpresse], Taptataila [siedendes Öl], Giripāta [Bergsturz], Ayasālaya [Eisenhaus]; Sūcyagni-Bhūrinirghāta [Nadel-Feuer-vielfacher-Donnerschlag], Vakrakaṇṭaka-Dānava [Krummdorn-Dämon], Śvabhojana-Vratapa [Hunde-Fraß], Karkaśāli-Mukholbaṇa; [die Hölle des] Eiter-, Blut-, Urin-, Kot-Verzehrs, [des] Umarmens erhitzter [eiserner] Bildnisse, Kālakūṭāgni-Śakala [Gift-Feuer-Splitter], Sarvaśastrāstrapātana [Fallen aller Waffen und Geschosse]; Prāṇarodha-Mahābhāra [Atem-Erstickung-schwere-Last], Krūrāśīviṣa-Vṛścika [grausame Giftschlangen und Skorpione], [die Hölle des] Abschneidens aller Glieder [und des Verzehrens] des eigenen Fleisches, [des] Stürzens auf erhitzte Bäume; die beiden [Höllen des] Pfahl-Aufspießens und Herabreißens, die übelriechende, das Verschlungenwerden durch Rākṣasas, den Pfeilhieb, die Vaitaraṇī [der Höllenfluss], Śaṅkamūla-Karālaka; Ameisen- und Blutegel[-Fraß], Speise für Geier und Reiher, die beiden [Höllen des] Herumwirbelns und Zerschmetterns, Śilāyantra-Śilādana [Steinpresse-Steinfraß]; die Ohren-[etwas]füllende [Hölle], die beiden [Höllen des] Durch-Türen-Schleuderns und Fesselns, Ketten, glühender Sand, Funken und Staubschauer; Kopf-, Vitalpunkt-, Gelenk-, Schädel-[Zerstörung], Wasser-Entzug u.a. – es gibt fürwahr einhundertacht Höllen, die Wohnstätten der Sünde.

Vers 40-44

anityanarakā ete tāmiśrandhatāmiśrakau / nityau dvau narakau tatra gatāyānti tamaḥ kramāt // 40 // adho lokeṣu ye devāḥ sarvamanvantareṣvapi / proktavyāpāraniratāḥ nāmāntaravivarjitāḥ // 41 // ayogyānāmihaproktanāmarūpāṇi sarvaśaḥ / ihaiva pūrvamanuṣu(ṣṭu) data evājña(mya)nāmakāḥ // 42 // ete manulaye sarvetyaktvā sthūlāni sūkṣmataḥ / svaprājñavaśagā yānti maharlokaṃ tadatyaye // 43 // prāpyasthūlāni ṛṣibhiḥ svapūrvaṃ pātike(prāntike) kramāt // 44 //

Diese sind die zeitlich begrenzten Höllen; Tāmisra und Andhatāmisra [aber] sind die beiden ewigen Höllen dort; die dorthin Gegangenen gehen der Reihe nach in die Finsternis ein. Die Götter, die in den unteren Welten [wohnen], in sämtlichen Manvantaras, sind ihren vorgeschriebenen Aufgaben hingegeben, ohne Wechsel des Namens. Die hier [zuvor] genannten Namen und Gestalten der Unwürdigen [wurden ihnen], in jeder Hinsicht, eben hier, in früheren Manu[-Zeitaltern], gegeben, [sie sind] eben als „zu Befehlende” benannt [?]. Diese alle, [wenn] der Manu[-Zeitraum] endet, verlassen [ihre] groben [Körper] zugunsten feinstofflicher [Körper] und gehen, von ihrer eigenen Weisheit geleitet, zum Maharloka, an dessen [des Manvantara] Ende. [Später,] am Rande des vorigen [Zyklus], erlangen sie der Reihe nach wieder grobe [Körper] durch/als Ṛṣis.
